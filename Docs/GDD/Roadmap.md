# 로드맵 (Roadmap)

아직 구현하지 않은 기획입니다. 구현되면 해당 GDD 문서로 옮기고 여기서 지웁니다.
층계 던전처럼 확정됐지만 진행 중인 큰 기획은 별도 기획안에서 관리하고, 여기에는 링크만 둡니다.

## 1. 전투 · 스탯

- **MP 사용처**: 무기 고유 스킬, 마법 무기가 MP를 소모. 스킬은 MP와 쿨타임을 함께 사용
- **장비 스킬 (`Q` `W` `E`)**: `SkillDataSO`는 있으나 런타임 사용처 없음. 쿨타임·MP 소모 처리 필요
- **추가 스탯**: 치명타(기본 1.5배), 회피(최대 75%), 방어구 관통력, 생명력 흡수, 피해 반사, 보호막, 상태 이상 저항. 관통력은 피해 공식에 자리만 있음([Combat.md](Combat.md) 2.6절)
- **무기 무게별 경직**: 가벼운 무기는 경직 없음, 무거운 무기는 1칸 넉백 또는 짧은 경직. 강한 군중 제어는 MP 스킬로만
- **무기 종류 구분**: `WeaponDataSO`에 근접 / 원거리 / 마법 타입 필드 추가
  - **원거리 무기**: 활·소총. 사거리 3~4칸, 가방 칸을 차지하는 탄약(겹침 가능)이 필요하고 장전 횟수 제한. 지금은 `Z` 키 시험용 투사체만 있음
  - **마법 무기**: 지팡이. 클릭한 칸에 장판을 깔고 잠시 후 피해. MP 소모
- **무기 상태 이상**: 화상, 넉백 등
- **악세서리 스킬**: 반지는 액티브 고정(대쉬, 무적, 즉시 회복), 목걸이·귀걸이는 패시브 고정(흡혈, 이동 쿨타임 감소) + 랜덤 부가 스탯. 잡화상 '하급 대쉬' 반지

## 2. 아이템

- **귀환석**: 층계 던전 07 문서 F10(Q31)
- **6층 숏컷 아이템** (07 문서 F8b, Q25): 5층 중간 보스를 한 번 클리어하면 제작이 영구 해금되는 1회용 소모품. 사용하면 6층에서 시작. 제작 비용은 해당 지역 일반 전리품 n개 + 희귀 전리품 n개 + 골드(n은 플레이 테스트로 결정). 클리어 이력 저장이 필요해 세이브(F8) 이후
- **보안 파우치 확장**: 기지 강화소에서 확장, 최대 4~6칸 (현재 2칸)
- **미확인 장비와 감정**: 미확인 장비는 스탯이 가려져 있고, 기지 감정소에서 골드를 내고 확인
- **등급 색상**: 일반(회색) / 희귀(파랑) / 전설(금색) 아이콘 테두리
- **열쇠와 잠긴 상자**: 구리·은·금 등급 상자를 같은 등급 열쇠로 염. 열쇠 데이터만 있고, 지금 상자는 공격으로 열림
- **횃불 장비**: 장착 시 시야 반경 증가
- **방어구 3분기**: 탐험형(이동속도·행동속도 강화) / 방어형(방어·HP 높음, 이동 느림) / 기동형(이동 빠름, MP·회피 증가, 방어 낮음). `ArmorBranch` enum만 있고 `ArmorDataSO`는 빈 클래스. 배낭은 방어구 테크트리에 종속되어 업그레이드

## 3. 몬스터

- **감지 각도**: 몬스터 데이터별 감지 반경·감지 각도(전방 시야각) 설정. 지금은 360도
- **정예**: 패턴 2개 이상 + 특성 1개 이상. 배치는 층 디자인에서 정함
- **보스**: 전용 장판 기믹, 페이즈 전환, 소환 패턴. 보스층 규칙은 07 문서 F6
- **특성별 AI 반응**:
  - `LIFESTEAL`: HP 30% 이하에서 위험 칸을 무시하고 공격 우선. 투사체 적중 시 흡혈 누락
  - `SHIELD`: 보호막이 있는 동안 경직·회피 인터럽트 면제 (슈퍼아머)
  - `EXPLOSIVE`: 빈사 시 플레이어에게 자폭 돌진

## 4. 던전

- **층계 던전 남은 단위**: 층 클리어·계단 잠금, 탈출구 확률 등장, 층 배율, 가방 25칸, 보스층, 귀환석, 지역 해금. 목록은 [Dungeon.md](Dungeon.md) 6절, 상세는 [07_Floor_Based_Dungeon_Design.md](../Architecture/07_Floor_Based_Dungeon_Design.md)
- **함정**: 독 늪(10초 지속 피해), 가시 함정(최대 HP 10% 즉시 피해). 함정으로 죽어도 전투 사망과 똑같이 처리. 지금은 함정 오브젝트 배치만 있고 피해 효과 없음
- **제단**: 회복 제단, 전투 버프 제단(다음 N번 전투 동안 공격·방어 상승), 희생 제단(장비를 바치고 버프)
- **층 기믹 (07 문서 F9)**: 장판 튜닝, 문 닫기, 턱 낙하, 넉백 기절
- **몬스터 호버 툴팁**: 마우스를 올리면 몬스터 정보와 감지 범위(ZOC) 표시

## 5. 기지

| 시설 | 기능 |
| --- | --- |
| 제작소 | 재료(몬스터 전리품)로 무기·방어구·배낭 설계도를 해금. 해금한 장비는 이후 골드나 저렴한 재료로 다시 제작 (사망 후 복구) |
| 감정소 | 미확인 장비 감정 |
| 강화소 | 보안 파우치 확장, 기본 스탯(HP·공격력) 영구 강화 |
| 퀘스트 | NPC가 특정 재료를 요구. 달성 시 호감도 상승 → 상점 품목 확장, 감정 비용 할인 (`NPCQuestSO`만 있음) |

- **무기 테크트리**: 기본 검에서 단검(공속)·대검(넉백) 등으로 분기. 상위 단계는 공격 범위, 이펙트, 상태 이상이 바뀜
- **경제**: 골드(소모품, 재제작, 감정 비용)와 재료(설계도 해금, 시설 강화)를 분리. 드랍 등급 비율 일반 70% / 희귀 25% / 전설 5%
- **장비 드랍 정리**: 무기·방어구·배낭은 제작 전용(던전 드랍 없음)으로 확정했지만, 지금 드랍 풀에는 장비를 넣을 수 있음. 제작소 구현 때 드랍 풀에서 제외

## 6. 하드 모드 (Heat)

- 노멀 클리어 후 해금. 던전 입장 전에 제약을 직접 골라 위험도 점수를 올림 (`HeatModifierSO`만 있음)

| 제약 | 효과 | 점수 |
| --- | --- | --- |
| 유약함 | 플레이어 최대 HP 30% 감소 | +2 |
| 강철 피부 | 몬스터 방어력 30% 증가 | +2 |
| 광폭화 | 몬스터 공격력 20% 증가 | +3 |
| 맹독 안개 | 탐험 중 지속 독 피해 | +4 |
| 탐욕의 저주 | 소모품 가격 2배 | +1 |

- 위험도 1점당 희귀 이상 드랍 확률 5% 복리 증가, 10점 이상이면 전설 확정 드랍
- **가방 크기는 하드 모드 제약으로 바꾸지 않습니다.** 제약은 전투·생존 난이도만 건드립니다.

## 7. UI

- **하단 HUD**: HP·MP 게이지(지금은 텍스트), 스킬 슬롯(`Q` `W` `E`). 소모품 퀵슬롯과 쿨타임 표시는 구현됨

## 8. 결정 보류

- **드랍 아이템의 안개 가시성**: 시야 밖이면 숨김(`VisibleOnly`) vs 한 번 본 칸이면 계속 보임(`RememberWhenExplored`, 현재 기본값). 두 모드를 테스트한 뒤 결정
