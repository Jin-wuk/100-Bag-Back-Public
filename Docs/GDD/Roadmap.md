# 로드맵 (Roadmap)

아직 구현하지 않은 기획입니다. 구현되면 해당 GDD 문서로 옮기고 여기서 지웁니다.

## 1. 전투 · 스탯

- **MP 사용처**: 무기 고유 스킬, 마법 무기가 MP를 소모. 스킬은 MP와 쿨타임을 함께 사용
- **방어력 피해 감소**: `피해 감소율 = DEF / (100 + DEF)`. 방어력이 높아도 100% 무적은 불가
  - 방어구 관통력: 적 DEF에서 직접 차감 (`Max(0, DEF - 관통력)`)
  - 음수 방어력: 받는 피해 증폭, 최대 2.0배로 제한
- **추가 스탯**: 치명타(기본 1.5배), 회피(최대 75%), 생명력 흡수, 피해 반사, 보호막, 상태 이상 저항
- **무기 무게별 경직**: 가벼운 무기는 경직 없음, 무거운 무기는 1칸 넉백 또는 짧은 경직. 강한 군중 제어는 MP 스킬로만
- **원거리 무기**: 활·소총. 사거리 3~4칸, 가방 칸을 차지하는 탄약(화살·총알, 겹침 가능)이 필요하고 장전 횟수 제한
- **마법 무기**: 지팡이. 클릭한 칸에 장판을 깔고 잠시 후 피해. MP 소모
- **악세서리 스킬**: 반지는 액티브(대쉬, 무적, 즉시 회복), 목걸이는 패시브(흡혈, 이동 쿨타임 감소). 스킬은 고정, 부가 스탯은 랜덤

## 2. 아이템

- **포션**: 전투 중에는 지속 회복 + 공용 쿨타임(5~10초) + 중첩 불가(시간만 갱신). 전투가 아니면 즉시 회복
- **귀환석**: 1칸을 차지하는 중도 탈출 소모품
- **보안 파우치**: 사망해도 잃지 않는 별도 칸. 기지에서 확장, 최대 4~6칸
- **미확인 장비와 감정**: 미확인 장비는 스탯이 가려져 있고, 기지 감정소에서 골드를 내고 확인
- **등급 색상**: 일반(회색) / 희귀(파랑) / 전설(금색) 아이콘 테두리
- **열쇠와 잠긴 상자**: 구리·은·금 등급 상자를 같은 등급 열쇠로 염. 현재는 상자를 배치만 하고 열 수 없음
- **버리기 공간 부족**: 주변에 빈 칸이 없으면 경고를 띄우고 버리기를 취소

## 3. 몬스터

- **정예**: 패턴 2개 이상 + 특성 1개 이상. 통로·상자·탈출 포탈 주변 배치
- **보스**: 전용 장판 기믹, 페이즈 전환, 소환 패턴
- **특성별 AI 반응**:
  - `LIFESTEAL`: HP 30% 이하에서 위험 칸을 무시하고 공격 우선
  - `SHIELD`: 보호막이 있는 동안 경직·회피 인터럽트 면제 (슈퍼아머)
  - `EXPLOSIVE`: 빈사 시 플레이어에게 자폭 돌진

## 4. 던전

- **함정**: 독 늪(10초 지속 피해), 가시 함정(최대 HP 10% 즉시 피해). 함정으로 죽어도 전투 사망과 똑같이 처리. 현재는 함정 오브젝트 배치만 있고 피해 효과 없음
- **제단**: 회복 제단, 전투 버프 제단(다음 N번 전투 동안 공격·방어 상승), 희생 제단(장비를 바치고 버프)
- **절차적 맵 생성**: 청크 단위 조립. 노멀 2x2, 하드 3x3
  - 청크마다 수작업 바리에이션 1~3개
  - 청크 경계 4면의 출입구 위치·너비는 모든 바리에이션에서 동일하게 맞춤
  - 청크 경계(병목)에 몬스터 배치
  - `ProceduralChunks` 모드와 `DungeonData`(노멀·하드)는 코드에 있으나 현재 사용하지 않음
- **추가 탈출 수단**: 귀환석, 층 보스 처치 시 즉시 탈출
- **탈출 연출**: 탈출 포탈에서 카운트다운 게이지

## 5. 기지

| 시설 | 기능 |
| --- | --- |
| 제작소 | 재료로 무기·방어구 설계도를 해금. 해금한 장비는 이후 골드나 저렴한 재료로 다시 제작 (사망 후 복구) |
| 잡화상 | 포션·탄약 등 소모품 판매 |
| 대장간 | 장비·전리품을 골드로 매각 |
| 감정소 | 미확인 장비 감정 |
| 강화소 | 보안 파우치 확장, 기본 스탯(HP·공격력) 영구 강화 |
| 퀘스트 | NPC가 특정 재료를 요구. 달성 시 호감도 상승 → 상점 품목 확장, 감정 비용 할인 |

- **무기 테크트리**: 기본 검에서 단검(공속)·대검(넉백) 등으로 분기. 상위 단계는 공격 범위, 이펙트, 상태 이상이 바뀜
- **방어구 테크트리**: 탐험형(가방 보너스, 방어 낮음) / 방어형(방어·HP 높음, 이동 느림) / 기동형(이동 빠름, MP·회피 증가, 방어 낮음)
- **경제**: 골드(소모품, 재제작, 감정 비용)와 재료(설계도 해금, 시설 강화)를 분리. 드랍 등급 비율 일반 70% / 희귀 25% / 전설 5%

> **정리가 필요한 부분**
> - 기획상 무기·방어구는 던전에서 드랍되지 않고 기지에서 제작하지만, 현재 구현에서는 장비도 일반 아이템과 같은 방식으로 드랍 풀에 넣을 수 있습니다.
> - 기획상 가방 용량은 탐험형 방어구 보너스로 늘리지만, 현재 구현은 별도의 `Backpack` 장비 부위로 처리합니다.

## 6. 하드 모드 (Heat)

- 노멀 클리어 후 해금. 던전 입장 전에 제약을 직접 골라 위험도 점수를 올림

| 제약 | 효과 | 점수 |
| --- | --- | --- |
| 유약함 | 플레이어 최대 HP 30% 감소 | +2 |
| 강철 피부 | 몬스터 방어력 30% 증가 | +2 |
| 광폭화 | 몬스터 공격력 20% 증가 | +3 |
| 맹독 안개 | 탐험 중 지속 독 피해 | +4 |
| 탐욕의 저주 | 소모품 가격 2배 | +1 |

- 위험도 1점당 희귀 이상 드랍 확률 5% 복리 증가, 10점 이상이면 전설 확정 드랍
- **가방 크기는 하드 모드 제약으로 바꾸지 않습니다.** 제약은 전투·생존 난이도만 건드립니다.

## 7. UI

- **하단 HUD**: HP·MP 게이지, 스킬 슬롯(`Q` `W` `E`), 소모품 슬롯(`1` `2` `3`), 쿨타임 표시
- **가방을 열면 일시정지**, 전투 중 장비 교체 잠금
- **결과 화면**: 생환 시 획득 전리품과 총 가치, 사망 시 잃은 아이템과 보존된 아이템(보안 파우치) 비교
