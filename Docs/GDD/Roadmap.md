# 로드맵 (Roadmap)

아직 구현하지 않은 기획입니다. 구현되면 해당 GDD 문서로 옮기고 여기서 지웁니다.
층계 던전처럼 확정됐지만 진행 중인 큰 기획은 별도 기획안에서 관리하고, 여기에는 링크만 둡니다.

## 0. 1차 마일스톤(MVP) 범위 [확정, 2026-11-17 유저 결정]

목표는 **정비 → 전투 → 판매/해금 → 정비** 사이클을 한 바퀴 굴려 보는 것입니다.

| 구분 | 항목 |
| --- | --- |
| MVP 포함 | 층계 던전 지역 1(07 문서 Q17: F0~F7 + F10 귀환석), 대장간 판매, 잡화상, 창고, **제작소(테크트리 해금, 5절)** |
| MVP 제외 | 강화소, 감정소(미확인 장비 포함), 퀘스트, 장비 스킬(`Q` `W` `E`)과 MP 사용처, 지역 해금·세이브(F8)·6층 숏컷(F8b, 07 문서 Q17) |

- 아래 항목 중 `[MVP 제외]` 표시가 있는 것은 사이클 플레이 테스트 뒤에 다시 봅니다.

## 1. 전투 · 스탯

- **무기 3종 (단검·창·대검)**: 대시 첫 실험 뒤 진행. 초안은 [09 다수 전투와 대시 기획안](../Architecture/09_Crowd_Combat_And_Dash_Design.md) 5절 (대시·근접 조건은 구현됨, [Combat.md](Combat.md) 2.9절)
- **MP 사용처** `[MVP 제외]`: 무기 고유 스킬. 스킬은 MP와 쿨타임을 함께 사용. 마법 무기는 MP를 쓰지 않음(아래 무기 종류 구분, 2026-11-17 유저 결정)
- **장비 스킬 (`Q` `W` `E`)** `[MVP 제외]`: `SkillDataSO`는 있으나 런타임 사용처 없음. 쿨타임·MP 소모 처리 필요
- **추가 스탯**: 치명타(기본 1.5배), 회피(최대 75%), 방어구 관통력, 생명력 흡수, 피해 반사, 보호막, 상태 이상 저항. 관통력은 피해 공식에 자리만 있음([Combat.md](Combat.md) 2.6절)
- **무기 무게별 경직**: 가벼운 무기는 경직 없음, 무거운 무기는 1칸 넉백 또는 짧은 경직. 강한 군중 제어는 MP 스킬로만
- **무기 종류 구분**: `WeaponDataSO`에 근접 / 원거리 / 마법 타입 필드 추가
  - **원거리 무기**: 활·소총. 사거리 3~4칸, 가방 칸을 차지하는 탄약(겹침 가능)이 필요하고 장전 횟수 제한. 지금은 `Z` 키 시험용 투사체만 있음
  - **마법 무기**: 지팡이. **MP를 소모하지 않고** 공격 특성으로 다른 무기와 구분: 느린 투사체, 광역 피해 등 (2026-11-17 유저 결정, MP 소모안 기각). 이전 초안의 "클릭한 칸에 장판을 깔고 잠시 후 피해"는 광역 피해 후보로 남김. 세부는 무기 기획 때 정함
- **무기 상태 이상**: 화상, 넉백 등
- **악세서리 스킬**: 반지는 액티브 고정(무적, 즉시 회복), 목걸이·귀걸이는 패시브 고정(흡혈, 이동 쿨타임 감소) + 랜덤 부가 스탯. 대쉬 반지는 기본 대시 도입으로 삭제(2026-11-09)
- **반지 패시브 특성 [논의 중]** (유저 아이디어, 2026-11-09): 전투의 단조로움을 반지 특성으로 푼다. 예: 전기 연쇄(주변 n마리 피해), 화상(지속 피해). Claude 의견: 확률 발동보다 3타 마무리·차징·대시·처치 같은 행동 조건으로 발동하게 해 플레이를 바꾸고, 무기는 공격 형태, 반지는 속성·상태 이상으로 역할을 나눈다. 상태 이상 시스템이 새로 필요. 미정: 위 액티브 반지 안 처리, 화상을 무기에서 반지로 옮길지. 구현은 대시 첫 실험 뒤

## 2. 아이템

- **6층 숏컷 아이템** (07 문서 F8b, Q25): 5층 중간 보스를 한 번 클리어하면 제작이 영구 해금되는 1회용 소모품. 사용하면 6층에서 시작. 제작 비용은 해당 지역 일반 전리품 n개 + 희귀 전리품 n개 + 골드(n은 플레이 테스트로 결정). 클리어 이력 저장이 필요해 세이브(F8) 이후
- **보안 파우치 확장** `[MVP 제외]`: 기지 강화소에서 확장, 최대 4~6칸 (현재 2칸)
- **미확인 장비와 감정** `[MVP 제외]`: 미확인 장비는 스탯이 가려져 있고, 기지 감정소에서 골드를 내고 확인
- **등급 색상**: 일반(회색) / 희귀(파랑) / 전설(금색) 아이콘 테두리
- **열쇠와 잠긴 상자**: 구리·은·금 등급 상자를 같은 등급 열쇠로 염. 열쇠 데이터만 있고, 지금 상자는 공격으로 열림
- **횃불 장비**: 장착 시 시야 반경 증가
- **방어구 3분기**: 탐험형(이동속도·행동속도 강화) / 방어형(방어·HP 높음, 이동 느림) / 기동형(이동 빠름, MP·회피 증가, 방어 낮음). `ArmorBranch` enum만 있고 `ArmorDataSO`는 빈 클래스. 배낭은 방어구 테크트리에 종속되어 업그레이드. 방어구는 설계도 없이 **분기별 재료**로 해금(예: 깃털 → 기동형, 가죽 → 방어형, 2026-11-19 유저 방향, [10 기획안](../Architecture/10_Crafting_TechTree_Design.md) 1.1절 B8). 몬스터를 기획할 때 지역마다 각 분기 재료를 주는 몬스터가 겹치는 층 범위에 있어야 함

## 3. 몬스터

- **감지 각도**: 몬스터 데이터별 감지 반경·감지 각도(전방 시야각) 설정. 지금은 360도
- **정예**: 패턴 2개 이상 + 특성 1개 이상. 배치는 층 디자인에서 정함
- **보스**: 지역 1(숲)은 10층 고정형 나무, 5층 2×2 이동형 중간 보스 **n종**. 초안은 [08 지역 1 보스 기획안](../Architecture/08_Region1_Boss_Design.md). 패턴은 몬스터 패턴 수정 때 함께 (지금은 임시 보스). 보스를 나눌 때(F6b) 설계도 드랍도 5층 = 2단계, 10층 = 3단계로 나눔(지금 임시 보스는 2단계만, [10 기획안](../Architecture/10_Crafting_TechTree_Design.md) B3)
- **골렘 보스 (던전 컨셉 지역 후보)**: 고정 본체 + 1칸 손 2개. 손을 잡으면 본체가 무방비
- **여러 칸 크기 몬스터**: 중간 보스 2×2 이동, 보스 3×3 고정(기획안 초안). 타일 점유·경로·피격 칸·안개 가시성·스폰 간격이 모두 영향 받음. F6 전에 별도 태스크
- **특성별 AI 반응**:
  - `LIFESTEAL`: HP 30% 이하에서 위험 칸을 무시하고 공격 우선. 투사체 적중 시 흡혈 누락
  - `SHIELD`: 보호막이 있는 동안 경직·회피 인터럽트 면제 (슈퍼아머)
  - `EXPLOSIVE`: 빈사 시 플레이어에게 자폭 돌진
- **원거리 공격·투사체 재설계** `[우선순위 낮음]` (유저 논의, 2026-11-17): 지금 투사체(`Projectile`)는 자유 각도 직진 + 콜라이더 판정이라 각도에 따라 위험 칸과 회피 거리가 들쭉날쭉함. 거의 새로 만드는 전제
  - **방향**: 몬스터 원거리 공격은 4방향으로 고정. 패턴을 복잡하게 하는 대신 몬스터 밀집도를 높여 단순한 공격의 조합으로 회피를 강제
  - **예고 2종**: 탄속형 투사체는 바닥 예고 없이 몬스터 아웃라인 강조만(보고 반응해서 피함). 즉발 레이저처럼 미리 보고 행·열을 비워야 하는 공격만 위험 칸 표시
  - **아웃라인**: 지금 `OutlineEffect`(허브)는 색 틴트라 전투용 1px 외곽선 셰이더가 따로 필요. 몬스터 자식 `Visual`에 적용하고 피격 플래시와 색을 겹쳐 쓰지 않게 분리
  - **대각선 공격은 보류**: 넣는다면 정확히 45°만 허용하고 칸 단위 판정(이러면 회피 거리가 항상 1칸). 벽 반사형 몬스터 후보
  - 미결 항목은 8절

## 4. 던전

- **층계 던전 남은 단위**: 높은 층 전용 상위 아이템(Q7), 보스 몬스터(F6b), 지역 해금. 목록은 [Dungeon.md](Dungeon.md) 7절, 상세는 [07_Floor_Based_Dungeon_Design.md](../Architecture/07_Floor_Based_Dungeon_Design.md)
- **함정**: 독 늪(10초 지속 피해), 가시 함정(최대 HP 10% 즉시 피해). 함정으로 죽어도 전투 사망과 똑같이 처리. 지금은 함정 프리팹만 있고 피해 효과가 없어 배치하지 않음(구현 때 층 디자인 마커로 배치)
- **제단**: 회복 제단, 전투 버프 제단(다음 N번 전투 동안 공격·방어 상승), 희생 제단(장비를 바치고 버프)
- **층 기믹 (07 문서 F9)**: 장판 튜닝, 문 닫기, 턱 낙하, 넉백 기절
- **몬스터 호버 툴팁**: 마우스를 올리면 몬스터 정보와 감지 범위(ZOC) 표시

## 5. 기지

| 시설 | 기능 |
| --- | --- |
| 제작소 **[MVP 포함]** | 재료(몬스터 전리품) + 골드로 무기·방어구·배낭을 해금. 무기 2단계 이상은 던전에서 얻은 설계도도 필요(2026-11-19, 방어구·배낭은 설계도 없음). 해금한 장비는 이후 골드로 다시 제작 (사망 후 복구). 기획안: [10 제작소 테크트리](../Architecture/10_Crafting_TechTree_Design.md) |
| 감정소 `[MVP 제외]` | 미확인 장비 감정 |
| 강화소 `[MVP 제외]` | 보안 파우치 확장, 기본 스탯(HP·공격력) 영구 강화 |
| 창고 확장 **[논의 필요]** | 무기·방어구 테크트리 해금처럼 창고를 탭(분류)으로 나누고, 창고 칸 수와 겹침 수를 따로 업그레이드하는 골드 소모처 (유저 아이디어, 2026-11-04). Claude 의견: 탭은 컨테이너 분리보다 창고 하나를 분류별로 걸러 보여주는 방식, 겹침은 등급별 표(예: 일반 10 / 희귀 5 / 전설 3에서 단계 상승). 지금은 30칸 + 겹침 10 임시 규칙 |
| 퀘스트 `[MVP 제외]` | NPC가 특정 재료를 요구. 달성 시 호감도 상승 → 상점 품목 확장, 감정 비용 할인 (`NPCQuestSO`만 있음) |

- **UI 개편**: 창고(분류 탭·정렬·퀵슬롯 줄), 상점(가방만·판매가), 툴팁, 테크트리 화면의 목표 구성은 [UI_Direction.md](UI_Direction.md)
- **무기 테크트리**: 기본 검에서 단검(공속)·대검(넉백) 등으로 분기. 상위 단계는 공격 범위, 이펙트, 상태 이상이 바뀜
- **경제**: 골드(소모품, 재제작, 감정 비용)와 재료(장비 해금, 시설 강화)를 분리. 등급 비율은 층별로 구현됨([Dungeon.md](Dungeon.md) 2절)
- **던전 암상인과 은행·현금 분리** `[MVP 제외]` (유저 아이디어, 2026-11-19): 중복 설계도 판매로 늘어나는 골드의 소모처이자, 원하는 설계도가 안 나올 때의 우회로
  - **골드 2종**: 은행 골드(지금의 지갑 골드, 사망해도 유지)와 현금. 기지 구매·제작·재제작은 은행 골드로 함
  - **현금**: 기지에서 은행 골드를 꺼내 만드는 아이템. 가방이나 보안 파우치 **1칸을 차지하고 겹침 상한 없음**. 사망하면 가방의 현금은 잃음. 파우치 2칸에서 "현금을 지킬까, 방금 주운 설계도를 지킬까"를 고르게 하려는 장치. 파우치가 확장되면(강화소) 현금 보관이 공짜가 되므로 그때 겹침 상한을 다시 봄
  - **암상인**: 던전 안에 낮은 확률로 나오는 상인. **현금으로만** 거래. 귀한 재료나 특정 설계도를 팜. 설계도 가격은 중복 설계도 판매가보다 높게(사서 되파는 이득 방지)
  - **출현 안내**: 던전 선택 지도의 지역에 "이 지역에 암상인이 출몰했습니다"만 표시하고 층은 알리지 않음. 안내가 있을 때만 현금을 들고 갈 이유가 생기게 하려는 것. 던전 선택 지도는 아직 기획 전(지역 해금 F8과 함께)
  - 정한 것(Claude 추천 채택): 현금은 **기지 인출로만** 생김, 입출금 **무료**, 판매 목록은 **지역 설계도 중 무작위 1~2개 + 귀한 재료**, **보스층(5·10층) 제외, 위층일수록 출현 확률 상승**
  - 미정: 확률·가격 수치(설계도 MVP 플레이 테스트 수치를 보고 정함), 안내가 뜬 판에 상인 출현을 보장할지(Claude 추천: 보장, 안내가 없는 판에는 출현 없음)
- **장비 드랍 정리**: 무기·방어구·배낭은 제작 전용(던전 드랍 없음)으로 확정했지만, 지금 드랍 풀에는 장비를 넣을 수 있음. 제작소 구현 때 드랍 풀에서 제외

## 6. 하드 모드 (Heat)

- 노멀 클리어 후 해금. 던전 입장 전에 제약을 직접 골라 위험도 점수를 올림 (`HeatModifierSO`만 있음)

| 제약 | 효과 | 점수 |
| --- | --- | --- |
| 유약함 | 플레이어 최대 HP 30% 감소 | +2 |
| 강철 피부 | 몬스터 방어력 30% 증가 | +2 |
| 광폭화 | 몬스터 공격력 20% 증가 | +3 |
| 맹독 안개 | 탐험 중 지속 독 피해 | +4 |
| 탐욕의 저주 | 소모품 가격 2배 | +1 |

- 위험도 1점당 희귀 이상 드랍 확률 5% 복리 증가, 10점 이상이면 전설 확정 드랍

  1. 탄속형의 최소 반응 시간: 예고가 없으니 "아웃라인 강조 시간 + 비행 시간"이 플레이어 1칸 이동(0.375초)보다 길어야 함. 최소 사거리를 둘지, 강조 시간 기준을 둘지

  3. 판정 방식: 칸 판정(탄이 든 칸 = 플레이어 점유 칸) vs 콜라이더. 칸 판정이면 이동 중인 플레이어를 출발 칸·도착 칸 중 어디로 볼지
  4. 레이저 범위: 벽까지 뻗는지, 사거리 N칸인지, 몬스터 몸에 막히는지
  5. 동시 발사 제한: 원거리 몬스터 여러 마리가 동시에 줄을 막아 안전 칸이 없어지지 않게 공격권(동시 조준 최대 N마리)이나 발사 시점 엇갈림을 둘지
  6. 몬스터 몸이 탄을 막는지: 지금 몬스터 탄은 다른 몬스터를 통과함. 막으면 근접 몬스터를 방패로 쓰는 위치 선정이 생김
  7. 밀집도: 층 전체 몬스터 수를 늘릴지, 총량은 두고 방 단위로 몰아 배치할지(전리품·가방 압박과 TTK가 함께 바뀜)
