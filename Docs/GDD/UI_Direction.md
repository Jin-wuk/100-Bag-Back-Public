# UI 방향 (UI Direction)

유저가 레퍼런스 화면으로 제시한 UI 방향입니다(2026-11-04). 4절 테크트리는 MVP용 단순 화면이 구현되었고(4.1절), 나머지는 **아직 구현하지 않았습니다**. 화면 구성과 기능만 적습니다. 아트·아이콘·색은 우리 것으로 만들며 레퍼런스 이미지는 레포에 두지 않습니다.

현재 UI는 [Items.md](Items.md) 7절, [Hub.md](Hub.md)를 참고하세요.

## 1. 창고 화면

| 영역 | 구성 |
| --- | --- |
| 상단 | 지갑 골드, 창고 총 가치 |
| 왼쪽 | 장비칸(무기·방어구·악세서리·배낭) + 가방 격자(5열). 가방 머리에 칸 수(예: 8/78), `전부 창고에 보관`, `정리` 버튼, 정렬(가치 / 무게 / 가치÷무게) |
| 가운데 | 보관함 목록(예: 무기 보관함, 액세서리 보관함, 의료품 보관함, 귀중품 금고). 창고 확장 업그레이드와 연결 ([Roadmap](Roadmap.md) 5절) |
| 오른쪽 | 창고 격자(5열). 머리에 칸 수(예: 547/580), 분류 탭 아이콘(전체·무기·탄약·방어구·…), `정리`, 정렬 3종 |
| 하단 | 퀵슬롯 줄. 아이템을 끌어다 등록 |

- **분류 탭은 창고 하나를 분류별로 걸러 보는 방식**입니다. 탭마다 별도 컨테이너를 두지 않습니다(옮길 때 어느 탭으로 갈지 규칙이 필요 없게).
- 우리 게임에는 무게 개념이 없으므로 정렬은 가치·등급·분류 기준으로 바꿉니다.

## 2. 상점 화면

| 영역 | 구성 |
| --- | --- |
| 상단 | 화면 이름, 지갑 골드, 뒤로가기 |
| 왼쪽 | **가방만** 보임(장비칸 없음). 칸마다 판매가 표시 |
| 오른쪽 | 상점 격자. 칸마다 아이콘·이름·가격. 목록 새로고침 타이머(도입 여부는 미정) |

- 지금은 잡화상 패널 하나에서 구매 목록과 하단 판매 칸을 함께 씁니다(대장간은 제작소로 바뀜, [Hub.md](Hub.md) 3절). 가방 칸마다 판매가를 보여 주는 개편은 아직입니다.

## 3. 아이템 칸과 툴팁

- **칸**: 등급 색 배경, 오른쪽 아래 수량, 아래쪽 이름.
- **툴팁**: 아이템에 마우스를 올리면 뜸. 이름, 스탯(무기: 피해·공격 속도·사거리 등), 판매가, **보유 수(가방·창고)**, 어디에 필요한지(제작·해금 재료로 쓰이는 곳) 표시.
- 툴팁은 창고·가방·상점·테크트리 어디서나 공통으로 씁니다.

## 4. 테크트리(해금) 화면

| 요소 | 구성 |
| --- | --- |
| 열(왼쪽 → 오른쪽) | 단계. 열 머리에 해금 조건(레퍼런스는 시설·레벨) |
| 노드 | 아이콘 + 이름(등급 색) + `?`(해금 조건·필요 재료) · 미리보기 · `이동`(제작·구매 화면으로) |
| 연결선 | 이전 단계 → 다음 단계 화살표. 한 노드에서 여러 갈래로 분기 |
| 상단 | 지갑 골드, 카테고리 선택(예: 무기 > 검), 아이템 이름 검색 |
| 하단 | 열마다 상태(해금됨 / 잠김 등) |

- 기획 연결: 제작소(전리품 + 골드로 해금, 무기 2단계 이상은 설계도 필요 → 골드만으로 재제작), 무기 분기(검 → 단검·대검), 방어구 3분기, 배낭은 방어구 탭의 한 줄 ([Roadmap](Roadmap.md) 5절, [10 제작소 기획안](../Architecture/10_Crafting_TechTree_Design.md)). 몬스터 전리품이 해금 재료를 겸합니다.
- 결정됨(10 기획안): 열은 **단순 단계(티어)**, 해금하면 장비 1개를 주고 이후는 **재제작**, 지역 진행은 노드마다 필요 지역으로 잠금. 배낭은 지역마다 1단계(총 4단계)이며 판매가 아니라 제작소 배낭 줄에서만 얻습니다.

### 4.1 MVP 구현 (C4)

| 요소 | 구현 |
| --- | --- |
| 탭 | 무기 / 방어구 2개. 방어구 탭은 투구·갑옷·신발·배낭 4줄 |
| 줄 | 왼쪽에 줄 이름, 오른쪽으로 단계 순 노드와 가로 연결선. 분기는 없음 |
| 노드 | 아이콘 + 이름 버튼, 상태별 색(숨김·선행 미충족·해금 가능·해금됨). 잠긴 지역 노드는 `???` |
| 상세 | 결과 장비 이름·단계·스탯, 재료별 `보유/필요`(모자라면 빨강), 골드, 버튼 하나(`Unlock` / `Craft` / `Locked`) |
| 상단 | 제목 `Blacksmith - Craft`, 지갑 골드 |

- 레퍼런스의 `?`·미리보기·`이동`, 검색, 열 머리 조건, 열 하단 상태는 아직 없습니다. 툴팁(3절)과 함께 개편할 때 넣습니다.

## 5. 추천 구현 순서

1. 툴팁 (독립적이고 모든 화면이 씀)
2. 상점 화면 개편 (가방만, 판매가 표시, 격자 상점)
3. 창고 화면 개편 (분류 탭, 정렬·정리, 전부 보관, 퀵슬롯 줄)
4. 창고 확장 (보관함 단위 칸 수·겹침 업그레이드, 기획 논의 후)
5. 테크트리 화면 개편 (MVP 단순 화면은 구현됨, 4.1절)
