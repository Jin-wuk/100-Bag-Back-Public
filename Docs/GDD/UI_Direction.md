# UI 방향 (UI Direction)

유저가 레퍼런스 화면으로 제시한 UI 방향입니다(2026-11-04). **아직 구현하지 않았고**, 화면 구성과 기능만 적습니다. 아트·아이콘·색은 우리 것으로 만들며 레퍼런스 이미지는 레포에 두지 않습니다.

현재 UI는 [Items.md](Items.md) 7절, [Hub.md](Hub.md)를 참고하세요.

## 1. 창고 화면

| 영역 | 구성 |
| --- | --- |
| 상단 | 지갑 골드, 창고 총 가치 |
| 왼쪽 | 장비칸(무기·방어구·악세서리·배낭) + 가방 격자(5열). 가방 머리에 칸 수(예: 8/78), `전부 창고에 보관`, `정리` 버튼, 정렬(가치 / 무게 / 가치÷무게) |
| 가운데 | 보관함 목록(예: 무기 보관함, 액세서리 보관함, 의료품 보관함, 귀중품 금고). 창고 확장 업그레이드와 연결 ([Roadmap](Roadmap.md) 5절) |
| 오른쪽 | 창고 격자(5열). 머리에 칸 수(예: 547/580), 분류 탭 아이콘(전체·무기·탄약·방어구·…), `정리`, 정렬 3종 |
| 하단 | 퀵슬롯 줄. 아이템을 끌어다 등록 |

- **분류 탭은 창고 하나를 분류별로 걸러 보는 방식**입니다. 탭마다 별도 컨테이너를 두지 않습니다(옮길 때 어느 탭으로 갈지 규칙이 필요 없게).
- 우리 게임에는 무게 개념이 없으므로 정렬은 가치·등급·분류 기준으로 바꿉니다.

## 2. 상점 화면

| 영역 | 구성 |
| --- | --- |
| 상단 | 화면 이름, 지갑 골드, 뒤로가기 |
| 왼쪽 | **가방만** 보임(장비칸 없음). 칸마다 판매가 표시 |
| 오른쪽 | 상점 격자. 칸마다 아이콘·이름·가격. 목록 새로고침 타이머(도입 여부는 미정) |

- 지금은 잡화상(구매)과 대장간 판매 칸이 나뉘어 있습니다. 한 화면에서 사고팔지는 개편 때 정합니다.

## 3. 아이템 칸과 툴팁

- **칸**: 등급 색 배경, 오른쪽 아래 수량, 아래쪽 이름.
- **툴팁**: 아이템에 마우스를 올리면 뜸. 이름, 스탯(무기: 피해·공격 속도·사거리 등), 판매가, **보유 수(가방·창고)**, 어디에 필요한지(제작·해금 재료로 쓰이는 곳) 표시.
- 툴팁은 창고·가방·상점·테크트리 어디서나 공통으로 씁니다.

## 4. 테크트리(해금) 화면

| 요소 | 구성 |
| --- | --- |
| 열(왼쪽 → 오른쪽) | 단계. 열 머리에 해금 조건(레퍼런스는 시설·레벨) |
| 노드 | 아이콘 + 이름(등급 색) + `?`(해금 조건·필요 재료) · 미리보기 · `이동`(제작·구매 화면으로) |
| 연결선 | 이전 단계 → 다음 단계 화살표. 한 노드에서 여러 갈래로 분기 |
| 상단 | 지갑 골드, 카테고리 선택(예: 무기 > 검), 아이템 이름 검색 |
| 하단 | 열마다 상태(해금됨 / 잠김 등) |

- 기획 연결: 제작소(재료로 설계도 해금 → 골드·재료로 재제작), 무기 분기(검 → 단검·대검), 방어구 3분기, 배낭은 방어구 트리에 종속 ([Roadmap](Roadmap.md) 5절). 몬스터 전리품이 해금 재료를 겸합니다.
- 배낭 3단계(Basic → Sturdy → Expedition)는 지금 잡화상 판매이며, 테크트리가 생기면 배낭 줄로 옮깁니다.
- 미정: 열을 시설 레벨로 할지 단순 티어로 할지, 해금 뒤 구매인지 제작인지, 지역(1~4) 진행과 열의 관계.

## 5. 추천 구현 순서

1. 툴팁 (독립적이고 모든 화면이 씀)
2. 상점 화면 개편 (가방만, 판매가 표시, 격자 상점)
3. 창고 화면 개편 (분류 탭, 정렬·정리, 전부 보관, 퀵슬롯 줄)
4. 창고 확장 (보관함 단위 칸 수·겹침 업그레이드, 기획 논의 후)
5. 테크트리 화면 (제작소 기획 확정 후)
