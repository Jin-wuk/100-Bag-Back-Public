# 프로젝트: Void Pouch - UI 및 아트 배치도 (UI/UX Layout GDD)

## 1. 씬(Scene) 기반 화면 분할 원칙
본 게임은 게임 엔진(Unity/Unreal) 환경을 고려하여, 무거운 씬 로딩을 최소화하고 UI 패널(팝업)을 적극 활용하는 **'3 씬 아키텍처(타이틀, 기지, 던전)'**를 채택한다.

## 2. 던전 씬 레이아웃 (Dungeon Scene)
던전 씬은 맵 탐험과 1대1 전투가 이루어지는 핵심 공간으로, 화면 영역을 상하로 크게 분할하여 사용한다.

### 2.1 상단 메인 뷰 (Exploration & Combat View / 화면의 70~80%)
*   **기본 상태 (탐험)**: 플레이어가 던전을 이동하며 전장의 안개를 걷어내고 함정, 보물상자, 제단 등과 상호작용하는 뷰.
*   **전투 상태 (Combat Overlay)**: 몬스터와 조우 시, 씬 전환 없이 상단 메인 뷰 위로 1대1 전투 팝업이 덮어씌워진다. (가운데에 거대한 몬스터 스프라이트와 적의 HP 바가 등장).

### 2.2 하단 액션 및 상태바 (Bottom HUD / 화면의 20~30%)
상단 뷰의 상황(탐험/전투)과 무관하게 항상 화면 하단에 고정되어 있는 유저 정보 영역이다.
*   **플레이어 스탯**: 내 체력(HP)과 마나(MP) 바 상시 노출.
*   **장비창 (Equipments)**: 현재 착용 중인 주요 장비 슬롯을 작게 표시하여 내 세팅을 상시 인지시킨다.
*   **스킬 퀵슬롯**: 전투 중 수동 개입(Interrupt)을 위한 액티브 스킬 버튼 3개가 큼직하게 배치된다.
*   **상호작용 아이콘**: 팝업창을 부르는 **'가방 아이콘'**과, 절체절명의 순간 누르는 **'도주(Flee) 버튼'**이 위치한다.

## 3. 핵심 팝업 패널 시스템 (Overlay Panels)
하단 상태바의 아이콘을 누르거나 특정 상황에 상단 뷰를 덮으며 열리는 UI 레이어.

### 3.1 통합 인벤토리 패널 (Inventory Panel)
*   하단 HUD의 **'가방 아이콘'**을 터치하거나 땅에 떨어진 전리품을 주울 때 팝업된다.
*   화면 좌측에는 **장비(Gear) 슬롯**들이 배치되어 현재 착용한 아이템 상태를 직관적으로 보여주며, 화면 우측에는 넓은 공간을 활용하는 **가방(Bag) 테트리스 뷰**가 동시에 노출된다.
*   가방과 장비창 간의 전환 탭을 없애고 1화면(1 Screen)으로 통합하여 유저가 내 셋업과 파밍 현황을 한눈에 볼 수 있다.
*   **더블클릭 시스템**: 유저는 가방 안의 아이템을 좌클릭 2번(더블클릭)하여 즉시 장비 슬롯에 장착시킬 수 있으며, 반대로 장착된 장비 슬롯을 더블클릭하면 즉시 가방의 빈칸으로 이동(자동 해제)된다.
*   가방이 열려 있는 동안 던전 탐험은 일시정지(Pause)된다.

### 3.2 기지 시설 통합 패널 (Hub Facility Panel)
*   기지 씬(Hub Scene)에서 특정 시설 클릭 시 팝업된다.
*   기본적으로 **'내 가방'과 '거대 창고(Stash)'가 동시에 띄워져 있는 상태**를 유지하며, 우측의 탭(Tab)을 넘겨가며 상점 구매, 대장간 판매, 미확인 장비 감정 등의 경제 활동을 가방 정리와 동시에 수행하도록 설계된다.
