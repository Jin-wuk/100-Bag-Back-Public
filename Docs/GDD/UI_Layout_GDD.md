# 프로젝트: Void Pouch - UI 및 아트 배치도 (UI/UX Layout GDD)

## 1. 씬(Scene) 기반 화면 분할 원칙
본 게임은 게임 엔진(Unity/Unreal) 환경을 고려하여, 무거운 씬 로딩을 최소화하고 UI 패널(팝업)을 적극 활용하는 **'3 씬 아키텍처(타이틀, 기지, 던전)'**를 채택한다.

## 2. 던전 씬 레이아웃 (Dungeon Scene)
던전 씬은 맵 탐험과 1대1 전투가 이루어지는 핵심 공간으로, 화면 영역을 상하로 크게 분할하여 사용한다.

### 2.1 상단 메인 뷰 (Exploration & Combat View / 화면의 70~80%)
*   **기본 상태 (탐험)**: 플레이어가 던전을 이동하며 전장의 안개를 걷어내고 함정, 보물상자, 제단 등과 상호작용하는 뷰.
*   **전투 상태 (Combat Overlay)**: 몬스터와 조우 시, 씬 전환 없이 상단 메인 뷰 위로 1대1 전투 팝업이 덮어씌워진다. 양 끝단에서 시작하는 플레이어와 몬스터 사이의 '물리적 거리(Grid/Track)'를 시각적으로 인지할 수 있는 트랙 UI가 함께 표시된다.
    *   **적 캐스팅 바 (Enemy Cast Bar)**: 정예 몬스터가 치명적인 특수 패턴을 준비할 때, 몬스터 스프라이트 아래에 차오르는 붉은색 캐스팅 바를 눈에 띄게 배치한다. (유저의 즉발 '기절' 스킬 개입 타이밍)
    *   **지속 회복(HoT) 상태 표시**: 전투 중 포션을 마셨을 때, 내 HP 바 옆에 위쪽 화살표(⬆️) 아이콘이나 초록색 이펙트를 띄워 현재 지속 회복이 적용 중임을 명확히 알린다.

### 2.2 하단 액션 및 상태바 (Bottom HUD / 화면의 20~30%)
상단 뷰의 상황(탐험/전투)과 무관하게 항상 화면 하단에 고정되어 있는 유저 정보 영역이다.
*   **플레이어 스탯**: 내 체력(HP)과 마나(MP) 바 상시 노출.
*   **장비 연동형 스킬 슬롯 (Item-bound Skill Slots)**: 고정된 액티브 스킬이 아닌, 현재 장착 중인 무기/방어구에 부여된 스킬들이 동적으로 표시되는 영역. 각 스킬 아이콘 하단에는 마나 소모량이, 상단에는 쿨타임 타이머가 표기되며 Q, W, E 등의 단축키가 표시된다.
*   **소모품 퀵슬롯 (Consumable Quick Slots)**: 인벤토리를 열지 않고 즉각적으로 포션/투척물을 사용할 수 있는 3~4칸의 슬롯 (단축키 1, 2, 3). 전투 중 포션 사용 시, 폭힐 방지 룰에 따라 퀵슬롯 전체에 글로벌 쿨타임(GCD) 패널이 어둡게 덮인다.
*   **상호작용 및 시스템 아이콘**: 마우스 클릭 외에도 키보드 조작을 유도하기 위해, 가방 아이콘에는 `[Tab]`, 도주(Flee) 버튼에는 `[Esc]` 또는 `[F]` 등 지정된 핫키 텍스트를 반드시 노출한다.

## 3. 핵심 팝업 패널 시스템 (Overlay Panels)
하단 상태바의 아이콘을 누르거나 특정 상황에 상단 뷰를 덮으며 열리는 UI 레이어.

### 3.1 통합 인벤토리 패널 (Inventory Panel)
*   하단 HUD의 **'가방 아이콘'**을 터치하거나 땅에 떨어진 전리품을 주울 때 팝업된다.
*   화면 좌측에는 **장비(Gear) 슬롯**들이 배치되어 현재 착용한 아이템 상태를 직관적으로 보여주며, 화면 우측에는 넓은 공간을 활용하는 **가방(Bag) 테트리스 뷰**가 동시에 노출된다.
*   가방과 장비창 간의 전환 탭을 없애고 1화면(1 Screen)으로 통합하여 유저가 내 셋업과 파밍 현황을 한눈에 볼 수 있다.
*   **더블클릭 시스템**: 유저는 가방 안의 아이템을 좌클릭 2번(더블클릭)하여 즉시 장비 슬롯에 장착시킬 수 있으며, 반대로 장착된 장비 슬롯을 더블클릭하면 즉시 가방의 빈칸으로 이동(자동 해제)된다. (※ 전투 중에는 자물쇠 UI와 함께 장착/해제가 잠금 처리됨)
*   **마우스 기반 테트리스 조작 (Tetris Controls)**: 
    *   **드래그 오프셋 유지**: 마우스 좌클릭으로 아이템을 집을 때, 마우스가 위치한 특정 셀(칸)의 내부 픽셀 단위 위치까지 정확히 기억하여 자연스러운 드래그감을 제공한다.
    *   **우클릭 제자리 회전 (Right-Click Rotation)**: 아이템을 드래그하는 도중 **마우스 우클릭**을 하면 아이템이 시계방향으로 90도 회전한다. 이때 회전의 중심축(Pivot)은 단순 기하학적 중앙이 아닌 **마우스가 현재 쥐고 있는 바로 그 칸(Cell)**이 되도록 보정하여, 인벤토리 가장자리에서도 유저가 직관적으로 배치 공간을 계산할 수 있도록 돕는다. (단축키 툴팁 대신 마우스 아이콘 툴팁으로 상시 안내)
*   가방이 열려 있는 동안 던전 탐험은 일시정지(Pause)된다.

### 3.2 기지 시설 통합 패널 (Hub Facility Panel)
*   기지 씬(Hub Scene)에서 특정 시설 클릭 시 팝업된다.
*   기본적으로 **'내 가방'과 '거대 창고(Stash)'가 동시에 띄워져 있는 상태**를 유지하며, 우측의 탭(Tab)을 넘겨가며 상점 구매, 대장간 판매, 미확인 장비 감정 등의 경제 활동을 가방 정리와 동시에 수행하도록 설계된다.

## 4. 특수 상황 UI (Extraction UI)
익스트랙션 장르의 하이라이트인 탈출 상황에 대한 UI 규정.

### 4.1 귀환석 카운트다운 (Recall Timer Overlay)
*   2x2 귀환석 사용 시, 화면 중앙 상단에 '10초 탈출 카운트다운' 텍스트가 거대하게 팝업되며 붉은색으로 점멸한다.
*   이 시간 동안 인벤토리 패널은 계속 활성화되어 있어야 하며, 유저는 남은 시간 안에 필사적으로 최종 가방 정리를 수행해야 한다.

## 5. 필드 탐색 및 인카운터 UI (Field & ZOC Overlay)
그리드(Grid) 기반의 맵 탐험 중 발생하는 정보 확인과 시각적 경고 시스템을 규정한다.
*   **몬스터 정보 탐색 (Hover / Press UI)**: 필드에 있는 고정형 몬스터 위에 마우스를 올리면(Hover), 몬스터의 기본 스탯(체력, 공격력)을 보여주는 미니 툴팁이 팝업된다. 동시에 해당 몬스터가 감지하는 '통제 구역(ZOC)' 타일 범위가 필드 바닥에 붉은색 반투명 오버레이로 점멸하여 유저의 거리 계산을 돕는다.
*   **스텔스 및 발각 경고 (Stealth Indicators)**: 플레이어가 ZOC의 바로 한 칸 바깥(안전지대 끝)에 도달하면 몬스터 머리 위에 노란색 '?' (경고) 아이콘이 뜬다. ZOC 내부로 진입하면 붉은색 '!' (발각) 아이콘이 뜨며 즉시 1대1 전투 화면(오버레이)으로 전환된다.

## 6. 결과 창 및 페널티 UI (Result & Extraction Screen)
탐험 종료 시 플레이어에게 득실을 명확하게 브리핑하는 화면.
*   **생환 성공 (Extraction Success)**: 획득한 모든 아이템 목록이 쏟아지듯 연출되며, 이번 탐험으로 벌어들인 총 가치(Gold Value)가 정산되어 표시된다.
*   **사망 (Death / KIA)**: 화면이 흑백이나 붉은 톤으로 어두워지며, '잃어버린 장비 및 전리품(Lost Items)'과 보안 파우치를 통해 '간신히 건진 전리품(Saved Items)' 목록을 좌우로 극명하게 대조하여 보여준다. 이를 통해 유저에게 상실감과 함께 다음 판을 향한 복수심(탐욕)을 자극한다.
