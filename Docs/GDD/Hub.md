# 기지 (Hub)

던전 사이에 돌아오는 기지입니다. 플레이어가 걸어 다니지 않고, 화면의 오브젝트를 클릭해 기능을 여는 **클릭형 로비**입니다.

## 1. 오브젝트

| 오브젝트 | 클릭 시 | 상태 |
| --- | --- | --- |
| 던전 포탈 | 던전 입장 UI를 열고, 입장하면 던전 씬으로 이동 | 구현 |
| 창고 | 창고 UI와 인벤토리·장비 UI를 함께 열기 (`Esc`로 닫기) | 구현 |
| 대장간 | 클릭만 인식. 기능은 [Roadmap](Roadmap.md) | 미구현 |
| 상점 | 클릭만 인식. 기능은 [Roadmap](Roadmap.md) | 미구현 |

- 마우스를 올리면 오브젝트에 외곽선이 표시됩니다.

## 2. 창고

- 던전에서 가져온 아이템을 맡기는 공간입니다. 사망해도 창고 아이템은 잃지 않습니다.
- 가방과 같은 1아이템 1칸 규칙을 따릅니다.
- 인벤토리와 창고 사이는 드래그 앤 드롭이나 `E` 키로 빠르게 옮깁니다.
- 창고·가방·장착 장비는 씬이 바뀌어도 유지됩니다.
