# 던전 (Dungeon)

맵 구성, 스폰 규칙, 전장의 안개, 탈출과 사망 규칙입니다.
클래스 구성은 [Dungeon_System_Map.md](../Architecture/ScriptMaps/Dungeon_System_Map.md)를 참고하세요.

## 1. 맵 구성

현재는 **수작업 고정 맵**(`FixedMap` 모드)을 사용합니다. 맵 위에 `DungeonZone`으로 구역을 지정하면, 던전에 들어갈 때마다 `DungeonGenerator`가 구역 규칙에 따라 몬스터와 오브젝트를 새로 배치합니다.

| 구역 | 역할 |
| --- | --- |
| `Start` | 플레이어 시작 위치 |
| `Combat` | 몬스터 배치 |
| `Chest` | 보물 상자 배치 |
| `Corridor` | 복도 몬스터 배치 |
| `Exit` | 탈출 포탈 후보 |

## 2. 배치 규칙

1. `Start` 구역에서 4방향 BFS로 실제로 걸어서 갈 수 있는 바닥 칸과 걸음 수를 구합니다. 벽 뒤의 빈 공간은 제외됩니다.
2. `Exit` 구역 후보 중 **걸음 수가 가장 먼 곳**에 탈출 포탈을 만듭니다.
3. 몬스터는 서로 3칸 이상 떨어지게, 시작 지점에서 5걸음 이내에는 배치하지 않습니다.
4. 배치가 끝나면 전장의 안개를 초기화해 시작 위치 주변만 보이게 합니다.

## 3. 전장의 안개

| 상태 | 표시 | 보이는 것 |
| --- | --- | --- |
| 미탐험 | 완전한 어둠 | 없음 |
| 탐험 | 반투명 안개 | 지형만 |
| 시야 | 투명 | 지형, 몬스터, 바닥 아이템 |

- **시야 반경**: 플레이어 기준 4칸. 가장자리는 부드럽게 흐려집니다.
- **벽 차단**: 플레이어와 각 칸 사이에 벽이 있으면 그 칸은 보이지 않습니다. 벽면 자체는 보입니다.
- **위쪽 벽 보정**: 탑다운 시점에서 위쪽 벽은 2칸 높이로 그려지므로, 벽 바로 위 칸도 함께 보이게 합니다.
- **한 번 탐험한 칸은 다시 미탐험으로 돌아가지 않습니다.**
- **몬스터·바닥 아이템**은 현재 시야 안에서만 보입니다. 상자처럼 고정된 오브젝트는 한 번 탐험하면 계속 보입니다.
- **보조 광원**: 맵에 놓인 광원 오브젝트(`FogVisionSource`)도 자기 반경만큼 시야를 밝힙니다. 플레이어가 발견해야 켜지게 설정할 수 있습니다.
- 시야 계산은 플레이어가 다른 칸으로 이동할 때만 수행합니다.

## 4. 탈출과 사망

| 결과 | 조건 | 처리 |
| --- | --- | --- |
| 생환 | 탈출 포탈 칸에 도달 | 가방과 장착 장비를 그대로 가지고 기지로 돌아감 |
| 사망 | HP 0 | 가방과 장착 장비를 모두 잃고 기지로 돌아감. 창고는 유지 |

- 던전을 나가면 몬스터, 바닥 아이템을 포함한 던전 상태가 모두 사라지고, 다음 입장 때 새로 배치됩니다.
