# 던전 (Dungeon)

층 구성, 배치 규칙, 상자, 전장의 안개, 층 클리어, 탈출과 사망 규칙입니다.
층계 던전의 전체 기획(확정 사항과 아직 구현하지 않은 부분)은 [07_Floor_Based_Dungeon_Design.md](../Architecture/07_Floor_Based_Dungeon_Design.md), 클래스 구성은 [Dungeon_System_Map.md](../Architecture/ScriptMaps/Dungeon_System_Map.md)를 참고하세요.

## 1. 층계 구조

던전은 **지역 × 10층** 구조입니다. 1층에서 시작해 위층 계단으로 10층까지 올라가며, 아래층으로는 돌아갈 수 없습니다. 현재는 지역 1만 있습니다.

| 층 | 디자인 | 비고 |
| --- | --- | --- |
| 1~4층 | 초반 풀(`EarlyPool`)에서 가중치로 1장 | |
| 5층 | 중간 보스층 고정 디자인 | |
| 6~9층 | 후반 풀(`LatePool`)에서 가중치로 1장 | |
| 10층 | 보스층 고정 디자인 | 위층 계단 없음 |

- 층 디자인은 수작업으로 만든 작은 고정 층 프리팹입니다(`FloorDesignSO`). 지역 설정(`RegionConfigSO`)이 디자인 풀과 층별 규칙(상자 굴림 횟수·확률, 탈출구 확률)을 가집니다.
- **한 판 안에서 같은 디자인은 다시 나오지 않습니다.** 풀 장수가 모자라면 에디터 검증이 막습니다.
- 위층 계단은 **잠긴 채로** 나오고 층을 클리어하면 열립니다(5절). 열린 계단을 밟으면 확인창 없이 **같은 씬 안에서** 다음 층을 새로 만듭니다. HP·가방 등 플레이어 상태는 그대로 이어집니다.
- 화면에 현재 층이 항상 표시되고(`Stage 1-3F`), 층에 들어설 때 배너가 뜹니다.

## 2. 배치 규칙

층 프리팹에는 시작점, 위층 계단, 탈출구, 상자 후보 위치가 마커로 찍혀 있고, 몬스터는 `DungeonZone` 구역으로 지정합니다.

1. 시작점에서 4방향 BFS로 실제로 걸어서 갈 수 있는 바닥 칸과 걸음 수를 구합니다. 벽 뒤의 빈 공간은 제외됩니다.
2. 계단·탈출구 마커와 그 주변 1칸에는 몬스터를 놓지 않고, **바닥 아이템도 떨어지지 않습니다**(몬스터·상자 드랍, 가방에서 버리기 모두. 그 너머 가장 가까운 빈 칸에 놓임). 10층은 계단이 없으므로 계단 마커 주변은 막지 않습니다.
3. **몬스터 수는 지역의 층별 규칙이 정합니다**(초기값 1~9층: 4, 4, 5, 5, 3, 6, 6, 7, 7. 5층은 중간 보스 옆 잡몹). 층 디자인의 몬스터 구역은 배치 영역으로만 쓰고, 구역마다 걸을 수 있는 칸 수 비율로 나눠 놓습니다. 10층은 층별 규칙이 없어 구역에 적힌 수(잡몹 2)를 씁니다.
4. 보스층(5·10층)은 층 디자인의 `BossSpawn` 마커에 지역 설정의 보스를 먼저 놓습니다. 잡몹도 보스와 3칸 이상 떨어집니다. 보스 프리팹이나 마커가 없으면 보스 없이 전원 처치 규칙으로 진행합니다.
5. 몬스터는 서로 3칸 이상 떨어지게, 시작점에서 5걸음 이내에는 배치하지 않습니다. 이 규칙 때문에 정한 수보다 적게 놓일 수 있습니다.
6. 함정은 피해 효과가 구현될 때까지 배치하지 않습니다.
7. 상자는 층별 규칙에 따라 굴림 횟수만큼 확률을 굴려, 당첨되면 아직 쓰지 않은 상자 후보 중 한 곳에 놓습니다(3절).
8. 배치가 끝나면 전장의 안개를 초기화해 시작점 주변만 보이게 합니다. 보스층은 안개 없이 시작합니다.

- **층 배율**: 층이 오를수록 몬스터가 강해지고 드랍 등급이 오릅니다. 값은 지역 설정(`RegionConfigSO`)에 있습니다.

| 층 | 몬스터 HP | 몬스터 ATK | 드랍 등급 (일반/희귀/전설) |
| --- | --- | --- | --- |
| 1층 | ×1.0 | ×1.0 | 70 / 25 / 5 |
| 5층 | ×1.4 | ×1.2 | 60 / 31.5 / 8.5 |
| 9층 | ×1.8 | ×1.4 | 50 / 38 / 12 |
| 10층 | ×1.9 | ×1.45 | 9층과 같음 |

  층마다 HP +10%, ATK +5%이고 등급 비율은 1~9층 선형입니다. 방어력과 드랍 개수는 그대로이고, 보스층도 같은 표를 씁니다.
- 층을 만들 때 규격(마커 개수, 계단과 탈출구 거리, 상자로 길이 막혀도 계단·탈출구에 갈 수 있는지)을 검사합니다.

## 3. 상자

| 규칙 | 내용 |
| --- | --- |
| 등장 | 층별 굴림 횟수 × 확률. 굴림 2회 층은 0~2개 |
| 열기 | 근접 공격이나 차징 공격으로 때리면 열림. 열쇠 없음 |
| 내용물 | 지역 상자 드랍 풀(`DropPool_Chest_Region1`)에서 떨어짐 |
| 길 막기 | 상자는 칸을 차지해 플레이어·몬스터가 지나갈 수 없음. 열린 뒤에도 그대로 막음 |

## 4. 전장의 안개

| 상태 | 표시 | 보이는 것 |
| --- | --- | --- |
| 미탐험 | 완전한 어둠 | 없음 |
| 탐험 | 반투명 안개 | 지형, 상자, 바닥 아이템 |
| 시야 | 투명 | 지형, 몬스터, 상자, 바닥 아이템 |

- **시야 반경**: 플레이어 기준 4칸. 가장자리는 부드럽게 흐려집니다.
- **보스층**: 5·10층은 처음부터 안개가 전부 걷힌 채 시작합니다.
- **벽 차단**: 플레이어와 각 칸 사이에 벽이 있으면 그 칸은 보이지 않습니다. 벽면 자체는 보입니다.
- **위쪽 벽 보정**: 탑다운 시점에서 위쪽 벽은 2칸 높이로 그려지므로, 벽 바로 위 칸도 함께 보이게 합니다.
- **한 번 탐험한 칸은 다시 미탐험으로 돌아가지 않습니다.** 층을 옮기면 새 층에서 처음부터 다시 시작합니다.
- **몬스터**는 현재 시야 안에서만 보입니다. **바닥 아이템과 상자**는 한 번 탐험한 칸에 있으면 시야 밖에서도 계속 보입니다(`RememberWhenExplored`). 바닥 아이템을 시야 안에서만 보이게 할지는 결정 보류입니다([Roadmap](Roadmap.md) 8절).
- **보조 광원**: 맵에 놓인 광원 오브젝트(`FogVisionSource`)도 자기 반경만큼 시야를 밝힙니다. 플레이어가 발견해야 켜지게 설정할 수 있습니다.
- 시야 계산은 플레이어가 다른 칸으로 이동할 때만 수행합니다.

## 5. 층 클리어

| 층 | 클리어 조건 | 클리어 순간 |
| --- | --- | --- |
| 일반층 (1~4, 6~9층) | 그 층 몬스터를 **소환수까지 모두** 처치 | 안개 전부 해제, 전투 상태 즉시 해제, 위층 계단 열림, 탈출구 확률 굴림 |
| 보스층 (5·10층) | `Boss` 등급 몬스터를 모두 처치. 보스가 배치되지 않은 층은 일반층처럼 전원 처치 | 남은 잡몹·소환수 즉시 사망(**전리품 없음**, 자폭 없음), 날아가는 투사체·예고 장판 제거, 이어서 일반층과 같은 처리. 탈출구는 **100%**. 그 층을 떠날 때까지 플레이어 **무적**(5층은 계단으로 오르는 순간 해제, 10층은 탈출까지). 화면 알림은 "Boss defeated - You are safe" |

- 클리어 판정은 층에 실제로 생성된 몬스터 기준입니다(간격 규칙 때문에 목표 수보다 적게 놓여도 클리어 가능). 자폭 몬스터는 퓨즈가 끝나 사라지는 순간 셉니다.
- **소환수**: 전리품을 떨어뜨리지 않고, 소환자가 죽어도 남습니다. 일반층에서는 클리어하려면 소환수도 잡아야 합니다. (소환 패턴은 아직 없음)
- **탈출구**: 클리어 순간 지역 설정의 층별 확률(1~9층)로 1번 굴려, 성공하면 층 디자인의 탈출구 위치에 포탈이 나타납니다. 보정 규칙은 없고, 위층으로 올라가면 사라집니다.
- **겹침 가드**: 클리어 순간 계단이나 탈출구 칸에 서 있었다면, 다른 칸으로 나갔다가 다시 밟아야 발동합니다.
- 클리어하면 화면에 알림이 뜹니다(탈출구가 열렸는지 함께 표시).
- 해로운 상태 이상 해제(기획 07 Q29)는 상태 이상 시스템이 아직 없어 해당 사항이 없습니다. 상태 이상을 구현할 때 보스 처치 정리에 넣습니다.

## 6. 탈출과 사망

| 결과 | 조건 | 처리 |
| --- | --- | --- |
| 생환 | 탈출 포탈 칸에 도달 → 확인창("탈출할까요?")에서 탈출, 또는 귀환석 사용 → 확인창에서 탈출 | 가방·장착 장비·보안 파우치를 가지고 기지로 돌아감 |
| 사망 | HP 0 | 가방과 장착 장비를 모두 잃고 기지로 돌아감. 보안 파우치·창고·지갑 골드는 유지 |

- 탈출 확인창이 떠 있는 동안 게임이 일시정지되고 조작이 잠깁니다. 취소하면 포탈 칸을 벗어났다 다시 밟아야 다시 묻습니다.
- **귀환석**: 전투가 아닐 때 어느 층에서든 쓸 수 있고, 5층·10층에서는 쓸 수 없습니다. 상세는 [Items.md](Items.md) 4.1절.
- 던전을 나가면 몬스터, 바닥 아이템을 포함한 던전 상태가 모두 사라지고, 다음 입장 때 1층부터 새로 만듭니다.
- 기지로 돌아오면 결과 화면이 뜹니다. 탈출·사망한 지역과 층(`Stage 1-3F`)이 함께 표시됩니다([Items.md](Items.md) 8절).
