# 전투 (Combat)

플레이어의 조작과 전투 규칙입니다. 몬스터 쪽 규칙은 [Monster_AI.md](Monster_AI.md)를 참고하세요.

## 1. 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 타일 1칸씩 4방향 이동 (대각선 없음). 누르고 있으면 연속 이동. 1칸 이동 시간은 기본 속도 8에서 0.375초 |
| `Space` | 대시. 누르고 있는 이동 방향(없으면 마지막으로 누른 방향)으로 2칸 (2.9절) |
| 마우스 이동 | 조준. 캐릭터 기준 8방향으로 스냅 |
| 마우스 왼쪽 클릭 | 근접 공격 (2타 콤보) |
| 마우스 오른쪽 길게 누르기 → 떼기 | 차징 강공격 (지금은 꺼 둠, 2026-11-24) |
| `Z` | 조준 방향으로 투사체 발사 (원거리 공격 시험용) |
| `1` `2` `3` | 퀵슬롯에 등록한 소모품 사용 ([Items.md](Items.md) 4절) |
| `Tab` | 가방(인벤토리) 열기 / 닫기. 열려 있는 동안 게임 일시정지 |

- 이동 방향(4방향)과 조준 방향(8방향)은 서로 독립입니다. 대각선의 적을 바라본 채로 물러날 수 있습니다.
- 이동은 칸마다 살짝 뛰는 연출로 표현합니다. 칸 하나를 건너는 동안 이동 프레임이 한 번 재생되고(도약→착지), 포물선 높이 0.08칸이고 늘어남·눌림과 좌우 기울기는 없습니다(프리팹 `PlayerMovement` 수치). 이동 프레임은 방향당 9프레임 한 사이클(왼발+오른발)이고, 칸 하나에 반 사이클(한 발, 0~4번)과 전체(0~8번) 중 어느 쪽으로 재생할지 `Player_AnimSet`의 `_moveCycleMode`로 고릅니다(비교 중, 기본 한 칸에 한 발). 한 칸에 한 발이면 같은 방향으로 이어 걸을 때 앞 절반·뒤 절반(4~8번)이 번갈아 나오고, 방향을 바꾸거나 멈췄다 걸으면 앞 절반부터 시작합니다. (2026-11-22) 서 있을 때는 마지막으로 움직이거나 공격한 방향을 봅니다(마우스 조준을 따라 돌지 않음). (2026-11-19 유저 결정)
- 캐릭터 발 위치: 플레이어와 몬스터 모두 발끝이 칸 중심보다 0.25칸 아래에 오도록 스프라이트 기준점(pivot)을 잡습니다. 늘어남·눌림 같은 크기 연출을 켜면 이 점을 기준으로 바뀝니다. 픽셀 밀도는 플레이어·몬스터 모두 PPU 36이라 0.25칸 = 9px입니다. 애니메이션 프레임(플레이어 48px, 몬스터 40px)은 방향마다 대기 프레임 중 가장 낮은 발끝의 아래 여백 + 9px을 기준점 y로 잡아, 같은 방향의 이동·공격 프레임도 같은 기준점을 씁니다(보스는 그림이 몸 칸에 딱 맞도록 PPU를 정합니다: 멧돼지 56px/2칸 = 28, 나무 80px/3칸 ≈ 26.67. 발끝은 몸 맨 아랫줄 칸 중심보다 0.25칸 아래, 2026-11-22.) (예: 플레이어 S 13/48, 몬스터 S 12/40). 몬스터 정지 이미지(32px, 애니 SO가 없을 때만 씀)는 (0.5, 9/32)(부엉이 10/32). (2026-11-22) PPU는 35~38 사이에서 조정할 수 있는 임시값입니다. (2026-11-19·20 유저 결정)

## 2. 행동 규칙

### 2.1 이동과 공격은 동시에 할 수 없다
- 타일 사이를 이동하는 동안에는 공격하지 않습니다.
- 공격 후에는 무기를 거두는 후딜레이(모션 락) 동안 이동할 수 없습니다. 대시로만 끊을 수 있습니다(2.9절).
- 플레이어는 매 순간 "움직일지, 때릴지"를 골라야 합니다.

### 2.2 선입력
- 이동·공격 중에 누른 입력은 버리지 않고 **한 칸짜리 슬롯**에 저장합니다.
- 칸에 도착하거나 후딜레이가 끝나는 순간 저장한 입력을 바로 실행합니다.
- 새 입력이 오면 덮어써서 가장 최근 입력 하나만 기억하고, 0.22초가 지난 입력은 버립니다.

### 2.3 공격

| 공격 | 규칙 | 데미지 배율 |
| --- | --- | --- |
| 1타 | 조준 방향으로 무기 히트박스 판정. 칼은 내려베기 이펙트, 맨손은 주먹 타격 이펙트 | 1.0x |
| 2타 | 칼은 올려베기 이펙트(무기 SO에 2타 전용 이펙트가 있으면 뒤집지 않음), 맨손은 주먹 이펙트를 뒤집어 씀. 이펙트 1.08배 | 1.15x |
| (3타 강타) | 콤보 타수(`PlayerController._comboHitCount`)를 3 이상으로 올릴 때만 나옴. 이펙트 확대, 화면 흔들림·히트스톱 강화 | 1.5x |
| 차징 | 오른쪽 버튼을 0.6초 이상 누른 뒤 떼면 전방 직선 2칸 전체 타격. 다 차기 전에 떼면 취소. **지금은 꺼 둠**(`_chargeAttackEnabled`, 2026-11-24) | 2.0x |

- 콤보는 2타입니다(1타 → 2타 → 다시 1타, 마무리 강타 없음). 맨손과 칼 모두 같습니다. (2026-11-24 유저 결정)

- 콤보는 마지막 공격 후 1.5초 안에 다시 공격하면 이어집니다. 사이에 이동해도 끊기지 않습니다.
- 공격 판정 칸은 잠시 "위험 칸"으로 표시되며, 몬스터가 회피할 칸을 고를 때 참고합니다. 기본 공격은 0.3초(공격 간격 약 0.55초보다 짧게, 2026-11-24), 차징 강공격은 1.2초입니다.

### 2.4 무기별 차이

무기는 `WeaponDataSO` 데이터로 정의하며, 코드 수정 없이 추가합니다.

| 항목 | 내용 |
| --- | --- |
| 히트박스 | `SingleTile`(1칸), `ForwardLine2`(전방 직선 2칸), `WideSweep3`(전방 3칸 횡베기) |
| 공격 속도 | 무기 기본 공속 → 후딜레이 길이 |
| 타격감 | 화면 흔들림·히트스톱 배율 |
| 이펙트 | 콤보 단계별·차징 이펙트. 칼 3종(Iron·Steel·Test)은 1타 `FX_SwordSlashFore`, 2타 `FX_SwordSlashBack`(pixelfx light, 2026-11-24). 맨손은 `Player.prefab`의 기본 근접 이펙트 `FX_PunchHit` |
| 캐릭터 애니 | 무기 SO의 `PlayerAnimSet`. 비우면 기본 칼 세트(`Player_Sword_AnimSet`). 무기가 없으면 맨손 세트(`Player_AnimSet`) |

### 2.5 타격 연출
- 공격이 맞으면 화면 흔들림과 짧은 히트스톱(순간 정지)이 일어납니다.
- 후딜레이는 히트스톱의 영향을 받지 않는 시간으로 계산해, 연출 때문에 조작 규칙이 바뀌지 않습니다.
- 가방을 열어 일시정지한 동안 히트스톱이 끝나도 일시정지가 풀리지 않습니다(시간 배율은 `GamePauseService` 한 곳에서만 바꿈).

### 2.6 피해 공식

```
최종 피해 = 공격 피해 × (1 - DEF / (100 + DEF))      (DEF ≥ 0, 최소 1)
최종 피해 = 공격 피해 × min(2.0, 2 - 100 / (100 - DEF)) (DEF < 0, 받는 피해 증폭)
```

- 공격 피해 = 공격력 × 공격 배율(2.3절). 방어력이 높아도 100% 무적은 되지 않습니다.
- 방어구 관통력은 양수 방어력에서만 뺍니다(`Max(0, DEF - 관통력)`). 현재 관통력을 주는 장비는 없습니다.
- 플레이어와 몬스터 모두 같은 공식을 씁니다 (`CombatMath.Mitigate`).

### 2.7 전투 상태
- 마지막으로 때리거나 맞은 뒤 **5초** 동안은 전투 중입니다.
- 전투 중에는 포션이 지속 회복으로 바뀝니다([Items.md](Items.md) 4절).

### 2.8 피격 무적
- 피해를 입으면 **0.5초** 동안 모든 피해를 무시합니다. 공격 종류와 상관없이 같습니다.
- 첫 0.1초는 캐릭터가 빨갛게, 그 뒤로 무적이 끝날 때까지 깜빡입니다. 일시정지 중에는 깜빡이지 않고 무적 시간도 흐르지 않습니다.
- 무적 중 맞은 공격은 피해·타격 연출이 없고, 투사체는 그대로 사라지며 돌진은 플레이어 앞에서 멈춥니다.
- 나중에 지속 피해(독 늪 등)를 구현할 때는 무적을 걸지도, 무적에 막히지도 않게 합니다.
- 몬스터에게는 적용하지 않습니다. 보스 처치 후 무적([Dungeon.md](Dungeon.md) 5절)과는 별개입니다.

### 2.9 대시
- `Space`로 상하좌우 2칸을 0.12초에 이동합니다. 쿨타임은 3초이고 발동 순간 시작하며, 일시정지 중에는 흐르지 않고 층을 옮겨도 이어집니다. 수치는 실험 초기값이며 Player 프리팹에서 바꿉니다.
- 경로 위의 몬스터는 넘어갑니다. 벽·상자에서는 멈춥니다. 가장 먼 빈 칸에 착지하고, 착지할 칸이 없으면 발동하지 않으며 쿨타임도 쓰지 않습니다. 칸은 화면 위치가 아니라 점유로 판정합니다.
- 공격 후 잠금(2.1절), 진행 중인 걸음, 차징(모은 힘은 사라짐)을 끊을 수 있습니다. 공격 주기는 초기화되지 않아, 대시 직후 누른 공격은 주기가 끝날 때 나갑니다.
- 걷는 중에는 칸 경계를 넘기 전이면 출발 칸, 넘었으면 목적지 칸에서 시작합니다(몬스터 피격 판정과 같은 기준).
- 대시 중 무적은 없습니다. 판정 순간 서 있는 칸으로 맞고, 맞아도 착지까지 이동합니다. 아이템·계단·탈출구는 착지 칸에서만 발동합니다.
- 던전 HUD의 퀵슬롯 바 오른쪽 칸에 남은 쿨타임이 표시됩니다.
- 기획 배경과 첫 실험은 [09 다수 전투와 대시 기획안](../Architecture/09_Crowd_Combat_And_Dash_Design.md)을 참고하세요.

## 3. 플레이어 스탯

| 스탯 | 기본값 | 현재 쓰임 |
| --- | --- | --- |
| HP | 100 | 0이 되면 사망 |
| MP | 50 | 소모처와 회복 수단(MP 포션)은 MVP 밖. 마법 무기도 MP를 쓰지 않음([Roadmap](Roadmap.md)) |
| 공격력 | 10 | 공격 피해 = 공격력 × 공격 배율 |
| 방어력 | 5 | 받는 피해 경감 (2.6절) |
| 이동 속도 | 8 | 타일 이동 시간 |
| 공격 속도 | 1.82 | 후딜레이 길이 = 1 ÷ 공격 속도 (약 0.55초). 무기에 고유 공속이 있으면 그 값을 씀 |
| 사거리 | 1 | 조준한 칸까지 공격 가능한 최대 거리 |

- 기본값은 플레이어 프리팹(`Player.prefab`) 기준입니다.
- 레벨과 경험치는 없습니다. 능력치는 장착한 장비로만 바뀝니다. 장비 교체는 기지에서만 할 수 있습니다.
