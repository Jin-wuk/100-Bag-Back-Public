# 전투 (Combat)

플레이어의 조작과 전투 규칙입니다. 몬스터 쪽 규칙은 [Monster_AI.md](Monster_AI.md)를 참고하세요.

## 1. 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 타일 1칸씩 4방향 이동 (대각선 없음). 누르고 있으면 0.15초 간격으로 연속 이동 |
| 마우스 이동 | 조준. 캐릭터 기준 8방향으로 스냅 |
| 마우스 왼쪽 클릭 | 근접 공격 (3타 콤보) |
| 마우스 오른쪽 길게 누르기 → 떼기 | 차징 강공격 |
| `Z` | 조준 방향으로 투사체 발사 (원거리 공격 시험용) |
| `1` `2` `3` | 퀵슬롯에 등록한 소모품 사용 ([Items.md](Items.md) 4절) |
| `Tab` | 가방(인벤토리) 열기 / 닫기. 열려 있는 동안 게임 일시정지 |

- 이동 방향(4방향)과 조준 방향(8방향)은 서로 독립입니다. 대각선의 적을 바라본 채로 물러날 수 있습니다.
- 이동은 바운스·틸트·스쿼시가 들어간 짧은 걸음 연출로 표현합니다.

## 2. 행동 규칙

### 2.1 이동과 공격은 동시에 할 수 없다
- 타일 사이를 이동하는 동안에는 공격하지 않습니다.
- 공격 후에는 무기를 거두는 후딜레이(모션 락) 동안 이동할 수 없습니다.
- 플레이어는 매 순간 "움직일지, 때릴지"를 골라야 합니다.

### 2.2 선입력
- 이동·공격 중에 누른 입력은 버리지 않고 **한 칸짜리 슬롯**에 저장합니다.
- 칸에 도착하거나 후딜레이가 끝나는 순간 저장한 입력을 바로 실행합니다.
- 새 입력이 오면 덮어써서 가장 최근 입력 하나만 기억하고, 0.22초가 지난 입력은 버립니다.

### 2.3 공격

| 공격 | 규칙 | 데미지 배율 |
| --- | --- | --- |
| 1타 | 조준 방향으로 무기 히트박스 판정 | 1.0x |
| 2타 | 이펙트를 뒤집어 반대 방향으로 베기 | 1.15x |
| 3타 (강타) | 이펙트 확대, 화면 흔들림·히트스톱 강화 | 1.5x |
| 차징 | 오른쪽 버튼을 0.6초 이상 누른 뒤 떼면 전방 직선 2칸 전체 타격. 다 차기 전에 떼면 취소 | 2.0x |

- 콤보는 마지막 공격 후 1.5초 안에 다시 공격하면 이어집니다. 사이에 이동해도 끊기지 않습니다.
- 공격 판정 칸은 잠시 "위험 칸"으로 표시되며, 몬스터가 회피할 칸을 고를 때 참고합니다.

### 2.4 무기별 차이

무기는 `WeaponDataSO` 데이터로 정의하며, 코드 수정 없이 추가합니다.

| 항목 | 내용 |
| --- | --- |
| 히트박스 | `SingleTile`(1칸), `ForwardLine2`(전방 직선 2칸), `WideSweep3`(전방 3칸 횡베기) |
| 공격 속도 | 무기 기본 공속 → 후딜레이 길이 |
| 타격감 | 화면 흔들림·히트스톱 배율 |
| 이펙트 | 콤보 단계별·차징 이펙트 |

### 2.5 타격 연출
- 공격이 맞으면 화면 흔들림과 짧은 히트스톱(순간 정지)이 일어납니다.
- 후딜레이는 히트스톱의 영향을 받지 않는 시간으로 계산해, 연출 때문에 조작 규칙이 바뀌지 않습니다.
- 가방을 열어 일시정지한 동안 히트스톱이 끝나도 일시정지가 풀리지 않습니다(시간 배율은 `GamePauseService` 한 곳에서만 바꿈).

### 2.6 피해 공식

```
최종 피해 = 공격 피해 × (1 - DEF / (100 + DEF))      (DEF ≥ 0, 최소 1)
최종 피해 = 공격 피해 × min(2.0, 2 - 100 / (100 - DEF)) (DEF < 0, 받는 피해 증폭)
```

- 공격 피해 = 공격력 × 공격 배율(2.3절). 방어력이 높아도 100% 무적은 되지 않습니다.
- 방어구 관통력은 양수 방어력에서만 뺍니다(`Max(0, DEF - 관통력)`). 현재 관통력을 주는 장비는 없습니다.
- 플레이어와 몬스터 모두 같은 공식을 씁니다 (`CombatMath.Mitigate`).

### 2.7 전투 상태
- 마지막으로 때리거나 맞은 뒤 **5초** 동안은 전투 중입니다.
- 전투 중에는 포션이 지속 회복으로 바뀝니다([Items.md](Items.md) 4절).

### 2.8 피격 무적
- 피해를 입으면 **0.5초** 동안 모든 피해를 무시합니다. 공격 종류와 상관없이 같습니다.
- 첫 0.1초는 캐릭터가 빨갛게, 그 뒤로 무적이 끝날 때까지 깜빡입니다. 일시정지 중에는 깜빡이지 않고 무적 시간도 흐르지 않습니다.
- 무적 중 맞은 공격은 피해·타격 연출이 없고, 투사체는 그대로 사라지며 돌진은 플레이어 앞에서 멈춥니다.
- 나중에 지속 피해(독 늪 등)를 구현할 때는 무적을 걸지도, 무적에 막히지도 않게 합니다.
- 몬스터에게는 적용하지 않습니다. 보스 처치 후 무적([Dungeon.md](Dungeon.md) 5절)과는 별개입니다.

## 3. 플레이어 스탯

| 스탯 | 기본값 | 현재 쓰임 |
| --- | --- | --- |
| HP | 100 | 0이 되면 사망 |
| MP | 50 | MP 포션으로 회복. 소모처는 [Roadmap](Roadmap.md) |
| 공격력 | 10 | 공격 피해 = 공격력 × 공격 배율 |
| 방어력 | 5 | 받는 피해 경감 (2.6절) |
| 이동 속도 | 8 | 타일 이동 시간 |
| 공격 속도 | 1.0 | 후딜레이 길이 |
| 사거리 | 1 | 조준한 칸까지 공격 가능한 최대 거리 |

- 기본값은 플레이어 프리팹(`Player.prefab`) 기준입니다.
- 레벨과 경험치는 없습니다. 능력치는 장착한 장비로만 바뀝니다. 장비 교체는 기지에서만 할 수 있습니다.
