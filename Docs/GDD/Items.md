# 아이템 (Items)

가방 규칙, 아이템 분류, 획득과 버리기, 사망 시 처리입니다.

## 1. 가방

| 규칙 | 내용 |
| --- | --- |
| 1아이템 1칸 | 크기와 모양에 관계없이 모든 아이템은 1칸을 차지 (같은 아이템은 `maxStack`까지 한 칸에 겹침) |
| 칸 수 | 기본 30칸 |
| 무게 | 기본 50. 아이템마다 무게가 있고, 합이 한도를 넘으면 넣을 수 없음 |
| 용량 증가 | `Backpack` 부위에 가방 장비를 장착하면 칸 수와 무게 한도가 늘어남 |

- 가방 장비를 벗어서 칸이 줄어들면, 넘치는 아이템은 바닥에 떨어집니다.

## 2. 아이템 분류

| 분류 | 내용 |
| --- | --- |
| 장비 (`Equipment`) | 부위: `Weapon`, `Helmet`, `Armor`, `Ring`, `Necklace`, `Backpack` |
| 소모품 (`Consumable`) | 분류만 존재. 사용 효과는 [Roadmap](Roadmap.md) |
| 재료 (`Material`) | 분류만 존재. 사용처는 [Roadmap](Roadmap.md) |
| 열쇠 (`Key`) | 분류만 존재. 잠긴 상자는 [Roadmap](Roadmap.md) |
| 골드 | 몬스터가 떨어뜨리는 재화 아이템 |

- **등급**: `Common`, `Rare`, `Legendary`
- 장비는 장착하면 공격력·방어력·HP 등 스탯에 더해집니다.
- 아이템 원본은 ScriptableObject(`ItemDataSO` 계열)이고, 획득한 아이템은 고유 ID를 가진 런타임 객체(`RuntimeItem`)로 따로 관리합니다.

## 3. 획득과 버리기

| 동작 | 규칙 |
| --- | --- |
| 드랍 | 몬스터가 죽으면 드랍 풀(`DropPoolSO`)에 따라 골드, 확정 아이템, 랜덤 아이템이 떨어짐 |
| 떨어지는 위치 | 기준 위치에서 가장 가까운 빈 칸. 한 칸에 아이템 하나. 벽 너머로는 떨어지지 않음 |
| 줍기 | 아이템이 있는 칸을 밟으면 자동으로 주움 |
| 가방이 가득 찼을 때 | 줍지 못하고 바닥에 그대로 남음 |
| 버리기 | 인벤토리 UI에서 바닥으로 버리면 플레이어 주변 빈 칸에 떨어짐 |

## 4. 인벤토리 UI

- `Tab`으로 인벤토리와 장비창을 엽니다. 인벤토리를 열어도 게임 시간은 흐릅니다.
- 드래그 앤 드롭으로 칸을 옮기고, 더블클릭으로 장착하거나 해제합니다.
- 기지에서는 창고와 인벤토리를 함께 열어 서로 옮길 수 있습니다 ([Hub.md](Hub.md)).
