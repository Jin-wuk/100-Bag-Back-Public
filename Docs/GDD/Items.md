# 아이템 (Items)

가방 규칙, 아이템 분류, 획득과 버리기, 소모품, 보안 파우치, 사망 시 처리입니다.

## 1. 가방

| 규칙 | 내용 |
| --- | --- |
| 1아이템 1칸 | 크기와 모양에 관계없이 모든 아이템은 1칸을 차지 (같은 아이템은 `maxStack`까지 한 칸에 겹침) |
| 칸 수 | **기본 25칸 + 배낭 장비 보너스.** 무게 개념은 없음 (칸 수만 제한) |
| 배낭 | `Backpack` 부위 장비. 기본 배낭(Basic) +5칸, 상위 배낭(Sturdy) +8칸, 최상위 배낭(Expedition) +10칸 ([07 층계 던전](../Architecture/07_Floor_Based_Dungeon_Design.md) 6절). 셋 다 잡화상에서 판매 |

- 배낭을 벗어서 칸이 줄어들면, 넘치는 아이템은 바닥에 떨어집니다.
- 기본 칸 25는 던전 `Player.prefab`과 허브 씬 `InventoryManager` 둘 다 같은 값입니다. 최종 수치는 플레이 테스트로 조정합니다.

## 2. 아이템 분류

| 분류 (`ItemCategory`) | 내용 | 겹침 |
| --- | --- | --- |
| 장비 (`Equipment`) | 8부위 장착 (2.1절) | 1 |
| 소모품 (`Consumable`) | HP·MP 포션, 귀환석 (4절) | 포션 5 / 귀환석 1 |
| 재료 (`Material`) | 몬스터 전리품. 제작 재료로 쓸 예정 ([Roadmap](Roadmap.md)) | 일반 2 / 희귀 1 / 전설 1 (창고에서는 10, [Hub.md](Hub.md) 4절) |
| 열쇠 (`Key`) | 구리·은·금. 데이터만 있음, 쓰임은 [Roadmap](Roadmap.md) | 10 |
| 귀중품 (`Valuable`) | 골드 가치가 높은 전리품. 기지에서 팔아 골드로 바꿈 (5절) | 아이템별 |

- **등급**: `Common`, `Rare`, `Legendary`
- 아이템 원본은 ScriptableObject(`ItemDataSO` 계열)이고, 획득한 아이템은 고유 ID를 가진 런타임 객체(`RuntimeItem`)로 따로 관리합니다.

### 2.1 장비

| 구분 | 부위 (`EquipType`) |
| --- | --- |
| 무기 | `Weapon` |
| 방어구 | `Helmet`(투구), `Armor`(갑옷), `Boots`(신발) |
| 배낭 | `Backpack` |
| 악세서리 | `Ring`(반지), `Necklace`(목걸이), `Earring`(귀걸이) |

- 장비는 장착하면 공격력·방어력·HP 등 스탯에 더해집니다.
- **장비 장착·해제는 기지에서만** 할 수 있습니다. 던전에서는 장비창이 잠깁니다.
- **획득 경로(기획 확정)**: 무기·방어구·배낭은 기지에서 해금·제작·구매하는 전용 자산이고 던전에서 드랍되지 않습니다. 악세서리는 던전 드랍 전용입니다. 제작소는 아직 없어 기본 무기·방어구·배낭은 잡화상에서 삽니다([Hub.md](Hub.md)).

## 3. 획득과 버리기

| 동작 | 규칙 |
| --- | --- |
| 드랍 | 몬스터가 죽거나 상자가 열리면 드랍 풀(`DropPoolSO`)에 따라 아이템이 떨어짐. 몬스터는 65% 확률로 자기 전리품 1개, 등급은 층 비율([Dungeon.md](Dungeon.md) 2절) |
| 떨어지는 위치 | 기준 위치에서 가장 가까운 빈 칸. 한 칸에 아이템 하나. 벽 너머로는 떨어지지 않음 |
| 줍기 | 아이템이 있는 칸을 밟으면 자동으로 주움 |
| 가방이 가득 찼을 때 | 줍지 못하고 바닥에 그대로 남음 |
| 버리기 | 가방 아이템 우클릭 → `버리기`. 플레이어 기준 반경 2칸 안의 빈 칸에 떨어짐. 빈 칸이 없으면 취소. 탈출구·계단 주변 1칸에는 떨어지지 않음([Dungeon.md](Dungeon.md) 2절) |
| 휴지통 | 휴지통 칸에 끌어다 놓으면 확인창 후 영구 삭제. 던전·기지 모두 있음 |
| 수량 선택 | 겹친 아이템을 버리기·삭제·판매·나누기할 때는 수량을 골라서 처리. 수량 창이 떠 있는 동안에는 아이템 드래그·더블클릭·우클릭·장비 해제가 막힘 |
| 나누기 | 우클릭 → `Split`. 가방·창고·보안 파우치(던전 포함)에서 고른 수량을 떼어 **가방의 앞쪽(왼쪽 위) 빈칸**에 넣음. 같은 아이템 묶음과 합치지 않고, 가방 겹침을 넘으면 여러 빈칸에 나눔(예: 5개 → 2+2+1). 가방 안에서 나눌 때는 원래 묶음에 1개 이상 남김. 1개짜리 아이템(어느 컨테이너든)이거나 가방에 빈칸이 없으면 버튼이 보이지 않음. 고를 수 있는 최대치가 1이면 수량 창 없이 바로 나눔 |

- 기지에서는 `버리기` 버튼이 보이지 않습니다(바닥이 없음). 대신 휴지통과 판매를 씁니다.

## 4. 소모품과 퀵슬롯

| 항목 | 규칙 |
| --- | --- |
| 포션 효과 | HP 포션·MP 포션. **전투 중**이면 5초 동안 나눠 회복(지속 회복) + 공용 쿨타임 7초. **전투가 아니면** 즉시 회복 |
| 쿨타임 | 공용 쿨타임 동안에는 다시 쓸 수 없음. 회복할 것이 없으면(체력 가득 등) 소모하지 않음 |
| 사용 방법 | 퀵슬롯 `1` `2` `3`, 또는 가방에서 더블클릭 |
| 퀵슬롯 등록 | 가방의 소모품을 퀵슬롯으로 끌어다 연결. 아이템은 가방에 그대로 있고, 쓰면 가방의 같은 종류 중 앞 칸부터 줄어듦 |
| 등록 유지 | 다 써도 등록은 남고, 기지에서 등록한 슬롯이 던전에서도 유지됨 |

- 전투 중 기준은 [Combat.md](Combat.md) 2.7절(마지막 타격·피격 후 5초)입니다.
- 퀵슬롯은 가방 칸만 셉니다. 보안 파우치의 포션은 퀵슬롯으로 쓰지 않습니다.
- 사용에 실패하면(체력 가득, 쿨타임, 귀환석 사용 불가) 화면에 이유가 잠깐 표시됩니다.

### 4.1 귀환석

| 항목 | 규칙 |
| --- | --- |
| 형태 | 가방 1칸, 겹침 1. 잡화상에서 200G (임시 가격, [Hub.md](Hub.md) 3절). 판매 불가 |
| 사용 조건 | 던전에서 **전투가 아닐 때**만. **5층·10층(보스층)에서는 사용 불가** |
| 사용 | 퀵슬롯 또는 가방 더블클릭 → 확인창("Use the Return Stone and leave?") → 확인하면 1개 소모하고 **즉시 탈출**(카운트다운 없음). 취소하면 소모하지 않음 |
| 결과 | 탈출 포탈과 같은 생환 처리([Dungeon.md](Dungeon.md) 6절). 확인창이 떠 있는 동안 일시정지 |

## 5. 골드

- 골드는 가방 칸을 차지하지 않는 **지갑 재화**입니다. 시작 골드는 1000G입니다.
- 던전에서 얻는 것은 골드가 아니라 **귀중품·재료 같은 전리품**이고, 기지 대장간에서 팔아야 지갑 골드가 됩니다. 판매가는 아이템별 지정 가격(`baseValue`) × 수량입니다. 전리품은 등급별로 일반 20G / 희귀 80G / 전설 300G입니다(초기값, 플레이 테스트로 조정). 층당 기대 가치는 약 160G입니다.
- 지갑 골드는 사망해도 잃지 않습니다.

## 6. 보안 파우치

- 사망해도 잃지 않는 별도 칸입니다. 처음 **2칸**이며, 확장은 [Roadmap](Roadmap.md)의 강화소에서 할 예정입니다.
- **장비는 넣을 수 없습니다.**
- 가방·창고와 드래그 앤 드롭으로 주고받습니다.
- 파우치로 옮기는 것은 비전투 상태에서만 됩니다. 던전에서는 전투 중(마지막 타격·피격 후 5초) 가방 열기 자체를 막고, 파우치는 가방 화면 안에서만 다룰 수 있기 때문입니다(07 문서 Q16).

## 7. 인벤토리 UI

- `Tab`으로 가방과 장비창을 엽니다. **가방이 열려 있는 동안 게임이 일시정지**됩니다.
- 던전에서 전투 중이면 가방이 열리지 않고 "Can't open the bag during combat." 안내가 뜹니다. 닫기는 언제든 됩니다. 층을 클리어하면 바로 비전투가 되어 열 수 있습니다.
- 다른 칸으로 옮길 때 대상이 다 받지 못하면 들어갈 만큼만 옮기고 나머지는 원래 칸에 남습니다(예: 창고의 재료 7개 → 가방 빈칸 2칸이면 2+2개만 이동).
- 드래그 앤 드롭으로 칸을 옮기고, 더블클릭으로 장착·해제(기지)하거나 포션을 사용합니다.
- 기지에서는 창고와 가방을 함께 열어 서로 옮길 수 있습니다 ([Hub.md](Hub.md)).

## 8. 사망과 생환

| 구분 | 가방 | 장착 장비 | 보안 파우치 | 창고 | 지갑 골드 |
| --- | --- | --- | --- | --- | --- |
| 생환 | 유지 | 유지 | 유지 | 유지 | 유지 |
| 사망 | 모두 잃음 | 모두 잃음 | 유지 | 유지 | 유지 |

- 기지로 돌아오면 결과 화면이 뜹니다. 제목 아래에 탈출·사망한 지역과 층(`Stage 1-3F`)을 표시하고, 생환이면 가져온 전리품과 총 가치, 사망이면 잃은 아이템과 보안 파우치로 지킨 아이템을 보여줍니다.
