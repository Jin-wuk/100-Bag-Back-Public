# 아이템 (Items)

가방 규칙, 아이템 분류, 획득과 버리기, 소모품, 보안 파우치, 사망 시 처리입니다.

## 1. 가방

| 규칙 | 내용 |
| --- | --- |
| 1아이템 1칸 | 크기와 모양에 관계없이 모든 아이템은 1칸을 차지 (같은 아이템은 `maxStack`까지 한 칸에 겹침) |
| 칸 수 | **기본 25칸 + 배낭 장비 보너스.** 무게 개념은 없음 (칸 수만 제한) |
| 배낭 | `Backpack` 부위 장비. 기본 배낭 +5칸, 상위 배낭 +8·+10칸 ([07 층계 던전](../Architecture/07_Floor_Based_Dungeon_Design.md) 6절) |

- 배낭을 벗어서 칸이 줄어들면, 넘치는 아이템은 바닥에 떨어집니다.
- **현재 데이터와 차이**: 25칸, 상위 배낭, 재료 겹침 2/1/1(2절)은 확정된 목표치이고 아직 데이터에 반영되지 않았습니다(07 문서 F5, Q5). 지금 데이터는 기본 35칸(`Player.prefab`, 코드 기본값 30), 기본 배낭 +10칸입니다.

## 2. 아이템 분류

| 분류 (`ItemCategory`) | 내용 | 겹침 |
| --- | --- | --- |
| 장비 (`Equipment`) | 8부위 장착 (2.1절) | 1 |
| 소모품 (`Consumable`) | HP·MP 포션 (4절) | 5 |
| 재료 (`Material`) | 몬스터 전리품. 제작 재료로 쓸 예정 ([Roadmap](Roadmap.md)) | 확정 목표: 일반 2 / 희귀 1 / 전설 1 (현재 데이터는 아이템별) |
| 열쇠 (`Key`) | 구리·은·금. 데이터만 있음, 쓰임은 [Roadmap](Roadmap.md) | 10 |
| 귀중품 (`Valuable`) | 골드 가치가 높은 전리품. 기지에서 팔아 골드로 바꿈 (5절) | 아이템별 |

- **등급**: `Common`, `Rare`, `Legendary`
- 아이템 원본은 ScriptableObject(`ItemDataSO` 계열)이고, 획득한 아이템은 고유 ID를 가진 런타임 객체(`RuntimeItem`)로 따로 관리합니다.

### 2.1 장비

| 구분 | 부위 (`EquipType`) |
| --- | --- |
| 무기 | `Weapon` |
| 방어구 | `Helmet`(투구), `Armor`(갑옷), `Boots`(신발) |
| 배낭 | `Backpack` |
| 악세서리 | `Ring`(반지), `Necklace`(목걸이), `Earring`(귀걸이) |

- 장비는 장착하면 공격력·방어력·HP 등 스탯에 더해집니다.
- **장비 장착·해제는 기지에서만** 할 수 있습니다. 던전에서는 장비창이 잠깁니다.
- **획득 경로(기획 확정)**: 무기·방어구·배낭은 기지에서 해금·제작·구매하는 전용 자산이고 던전에서 드랍되지 않습니다. 악세서리는 던전 드랍 전용입니다. 제작소는 아직 없어 기본 무기·방어구·배낭은 잡화상에서 삽니다([Hub.md](Hub.md)).

## 3. 획득과 버리기

| 동작 | 규칙 |
| --- | --- |
| 드랍 | 몬스터가 죽거나 상자가 열리면 드랍 풀(`DropPoolSO`)에 따라 아이템이 떨어짐 |
| 떨어지는 위치 | 기준 위치에서 가장 가까운 빈 칸. 한 칸에 아이템 하나. 벽 너머로는 떨어지지 않음 |
| 줍기 | 아이템이 있는 칸을 밟으면 자동으로 주움 |
| 가방이 가득 찼을 때 | 줍지 못하고 바닥에 그대로 남음 |
| 버리기 | 가방 아이템 우클릭 → `버리기`. 플레이어 기준 반경 2칸 안의 빈 칸에 떨어짐. 빈 칸이 없으면 취소. 탈출구·계단 주변 제외는 미구현([Dungeon.md](Dungeon.md) 6절) |
| 휴지통 | 휴지통 칸에 끌어다 놓으면 확인창 후 영구 삭제. 던전·기지 모두 있음 |
| 수량 선택 | 겹친 아이템을 버리기·삭제·판매할 때는 수량을 골라서 처리 |

- 기지에서는 `버리기` 버튼이 보이지 않습니다(바닥이 없음). 대신 휴지통과 판매를 씁니다.

## 4. 소모품과 퀵슬롯

| 항목 | 규칙 |
| --- | --- |
| 포션 효과 | HP 포션·MP 포션. **전투 중**이면 5초 동안 나눠 회복(지속 회복) + 공용 쿨타임 7초. **전투가 아니면** 즉시 회복 |
| 쿨타임 | 공용 쿨타임 동안에는 다시 쓸 수 없음. 회복할 것이 없으면(체력 가득 등) 소모하지 않음 |
| 사용 방법 | 퀵슬롯 `1` `2` `3`, 또는 가방에서 더블클릭 |
| 퀵슬롯 등록 | 가방의 소모품을 퀵슬롯으로 끌어다 연결. 아이템은 가방에 그대로 있고, 쓰면 가방의 같은 종류 중 앞 칸부터 줄어듦 |
| 등록 유지 | 다 써도 등록은 남고, 기지에서 등록한 슬롯이 던전에서도 유지됨 |

- 전투 중 기준은 [Combat.md](Combat.md) 2.7절(마지막 타격·피격 후 5초)입니다.
- 퀵슬롯은 가방 칸만 셉니다. 보안 파우치의 포션은 퀵슬롯으로 쓰지 않습니다.

## 5. 골드

- 골드는 가방 칸을 차지하지 않는 **지갑 재화**입니다. 시작 골드는 1000G입니다.
- 던전에서 얻는 것은 골드가 아니라 **귀중품·재료 같은 전리품**이고, 기지 대장간에서 팔아야 지갑 골드가 됩니다. 판매가는 아이템별 지정 가격(`baseValue`) × 수량입니다.
- 지갑 골드는 사망해도 잃지 않습니다.

## 6. 보안 파우치

- 사망해도 잃지 않는 별도 칸입니다. 처음 **2칸**이며, 확장은 [Roadmap](Roadmap.md)의 강화소에서 할 예정입니다.
- **장비는 넣을 수 없습니다.**
- 가방·창고와 드래그 앤 드롭으로 주고받습니다.
- **확정, 미구현(07 문서 F5, Q16)**: 파우치로 옮기는 것은 비전투 상태에서만 됩니다. 전투 중에는 가방 열기 자체를 막습니다. 지금은 전투 중에도 열 수 있습니다.

## 7. 인벤토리 UI

- `Tab`으로 가방과 장비창을 엽니다. **가방이 열려 있는 동안 게임이 일시정지**됩니다.
- 드래그 앤 드롭으로 칸을 옮기고, 더블클릭으로 장착·해제(기지)하거나 포션을 사용합니다.
- 기지에서는 창고와 가방을 함께 열어 서로 옮길 수 있습니다 ([Hub.md](Hub.md)).

## 8. 사망과 생환

| 구분 | 가방 | 장착 장비 | 보안 파우치 | 창고 | 지갑 골드 |
| --- | --- | --- | --- | --- | --- |
| 생환 | 유지 | 유지 | 유지 | 유지 | 유지 |
| 사망 | 모두 잃음 | 모두 잃음 | 유지 | 유지 | 유지 |

- 기지로 돌아오면 결과 화면이 뜹니다. 생환이면 가져온 전리품과 총 가치, 사망이면 잃은 아이템과 보안 파우치로 지킨 아이템을 보여줍니다.
