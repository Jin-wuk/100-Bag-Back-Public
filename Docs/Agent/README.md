# Agent

AI 코딩 에이전트와 함께 개발하면서 직접 작성한 에이전트용 개발 지침입니다.
작업 전 지시 확인, 문서와 코드 동기화, 커밋 규칙 등을 정해 두고 에이전트가 따르도록 운영했습니다.

이 폴더의 파일이 규칙 원본이며, `CLAUDE.md`(Claude)와 `GEMINI.md`(Gemini 검토자)가 불러와 읽습니다.
