# 00. 공통 아키텍처 가이드라인 (Universal Architecture Guidelines)
프로젝트 'Dimension Looter' 전체를 관통하는 핵심 설계 원칙입니다.

## 1. 아키텍처 패턴: 역할 분리와 단방향 데이터 흐름 (MVC/MVP)
게임의 데이터 연산과 UI 화면 렌더링을 엄격히 분리합니다.

*   **Model (데이터 & 로직)**: 순수 C# 클래스(POCO). 유니티 엔진(`MonoBehaviour`)에 의존하지 않으며 상태와 비즈니스 규칙을 담당합니다.
*   **Manager (통제탑)**: 게임의 룰을 관장. 외부 입력을 받아 Model을 갱신하고, 상태 변화 발생 시 이벤트를 발생(`Invoke`)시킵니다.
*   **View (UI)**: `MonoBehaviour` 기반. 스스로 판단/연산하지 않고, 오직 Manager의 이벤트를 구독(Observer 패턴)하여 화면을 새로고침합니다.

**✅ 단방향 흐름 (Event Flow):** View(입력) -> Manager(검증 및 데이터 갱신) -> Event 발생 -> View(화면 렌더링)
> 스파게티 코드를 방지하는 최우선 원칙: "UI는 스스로 상태를 결정(연산)하지 않고, 오직 매니저의 이벤트를 구독하여 화면을 갱신하기만 한다."

## 2. 매니저 시스템 및 생명주기
*   **Global 매니저 (`GameManager`, `InventoryManager`, `DataManager`)**
    *   게임 전체 상태 및 씬 전환 간에도 유지되어야 하는 유저 데이터를 관리. (`DontDestroyOnLoad`)
*   **Scene-Specific 매니저 (`CombatManager` 등)**
    *   해당 씬(던전 등)에서만 유효한 데이터를 관리. 씬 전환 시 파괴되어 메모리를 반환.
*   *주의사항*: 싱글톤 패턴을 무분별하게 사용하면 결합도가 높아지므로, 시스템 간 결합은 최대한 인터페이스나 이벤트(Action)를 통해 풀어냅니다.

## 3. 데이터 파이프라인 분리
정적 기획 데이터와 동적 유저 데이터를 철저히 분리하여 관리합니다.
*   **정적 데이터 (Static/Master Data)**: 기획자가 작성한 CSV/JSON 등의 불변 데이터. 게임 초기화 시 파싱되어 `DataManager`에 읽기 전용(Read-Only)으로 캐싱됩니다. (예: 아이템 스펙 테이블)
*   **동적 데이터 (Save/User Data)**: 런타임에 변하는 유저 데이터 (인벤토리 상태, 골드 등). 특정 시점에 하나의 객체(`SaveData`)로 묶여 직렬화 후 로컬 스토리지에 저장됩니다.

## 4. 코드 최적화 및 안정성 원칙
*   **상태 기계 (FSM)**: 상태 처리를 위해 거대한 `switch-case`문을 지양하고, 각 상태를 독립된 클래스(`IState`)로 분리합니다(SRP 준수). 상태 객체는 딕셔너리에 캐싱하여 가비지 컬렉션(GC) 스파이크를 방지합니다.
*   **오브젝트 풀링 (Object Pooling)**: UI 타일, 데미지 텍스트, 투사체 등 자주 생성/파괴되는 객체는 반드시 풀링하여 재사용합니다.
*   **메모리 누수 방지 (중요)**: View 스크립트 등에서 이벤트를 구독할 때는 `OnEnable`에서 더하고(`+=`), `OnDisable` 또는 `OnDestroy`에서 **반드시 해제(`-=`)** 해야 합니다. 이벤트 호출 시에는 널 조건부 연산자(`?.Invoke()`)를 사용합니다.

## 5. 폴더 구조 및 네이밍 규약
*   **폴더 구조** (`Assets/Scripts/` 하위):
    *   `Core/`: 인터페이스, 유틸리티, 기본 설정
    *   `Data/`: 데이터 모델 (정적/동적)
    *   `Managers/`: 전역/씬 통괄 매니저
    *   `UI/`: 화면 렌더링 담당
    *   `Gameplay/`: 전투, 인벤토리 배치, 상호작용 로직 등
*   **네이밍 컨벤션**:
    *   클래스/메서드: `PascalCase`
    *   인터페이스: `I` + `PascalCase` (예: `IInteractable`)
    *   비공개 멤버 변수(Private): `_camelCase`
    *   지역 변수(Local): `camelCase`
