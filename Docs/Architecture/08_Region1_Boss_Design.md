# 지역 1(숲) 보스 기획안

07 문서 F6b(보스 몬스터)의 방향을 정리합니다. **구현 전 초안**이며, 패턴과 수치는 몬스터 패턴 수정 때 함께 확정하고 플레이 테스트로 조정합니다.
보스층 공통 규칙(안개 없음, 처치 후 무적 등)은 [Dungeon.md](../GDD/Dungeon.md) 5절에 구현되어 있습니다.

**재계산 필요 (2026-11-05):** 아래 예고 시간은 잠금 0.5초 전제입니다. 이동 0.375초/칸과 2칸 대시([09 문서](09_Crowd_Combat_And_Dash_Design.md))가 확인·결정됐으므로 패턴 확정 때 다시 계산합니다.

## 1. 결정 사항 (유저, 2026-11-05)

| 항목 | 결정 |
| --- | --- |
| 지역 1 컨셉 | 숲 |
| 5층 중간 보스 | 2×2, 이동, 독특한 공격 패턴. **중간 보스는 종류가 n개**(n은 미정) |
| 10층 보스 | ~~고정형~~ → **3×3 이동형**(2026-11-22 유저 변경), 다음 지역 해금 조건. 나무 느낌 |
| 보스방 지형 | 기둥 같은 별도 지형 없음 |
| 패턴 피해 상한 | 두지 않음. 피해를 극단적으로 높게 잡지 않는 것으로 대응 |
| 피격 무적 | 모든 피격에 일정하게 ([Combat.md](../GDD/Combat.md) 2.8절) |
| 패턴 구현 시점 | 몬스터 패턴 수정 때 함께 |
| 손 2개 부위형 보스 | 골렘이 연상되므로 던전 컨셉 지역의 보스 후보로 둠 |

**미정**: 중간 보스 종류 수 n과 등장 방식(한 판에 어떤 종류가 나오는지). 지금 `RegionConfigSO`는 5층 보스 프리팹을 1개만 가지므로 n종을 구현할 때 목록으로 바꿉니다.

## 2. 구현 순서

1. 피격 무적
2. 몬스터 패턴 수정 + 여러 칸 점유 + 고정형 (패턴 기준점을 "몬스터 칸 하나"에서 몸 전체로 넓힘)
3. 나무 패턴 시험판 (임시 그림)
4. 2×2 이동 + 중간 보스

**진행 (2026-11-22, B1):** 여러 칸 점유·이동 기반 구현. 크기는 `MonsterDataSO.footprint`. 나무가 이동형으로 바뀌어 고정 여부(`isStationary`)는 두지 않았다. 3절 나무 패턴 초안(뿌리 매듭 등)은 고정형 기준이라 B3에서 이동형에 맞게 다시 기획한다.

크기와 고정 여부는 `MonsterDataSO` 데이터(`footprint`, `isStationary`)로 두어, 플레이 테스트 결과에 따라 바꿔 볼 수 있게 합니다. 칸 기준점은 좌하단, 스프라이트는 몸 중심에 맞춥니다. 구현 비용은 고정형이 싸고 이동형이 비쌉니다(이동·경로·거리 계산이 모두 1칸 기준).

## 3. 초안: 10층 고대 나무 (3×3 고정, 맵 상단 중앙)

**공격 기회**: 본체 좌우, 본체 중심 칸 기준 체비쇼프 3~4칸에 뿌리 매듭 2개.

- 2~3타에 부서지는 오브젝트(`IAttackInteractable`). 클리어 판정·전리품과 무관합니다.
- 둘 다 부수면 나무가 6초 무방비: 받는 피해 100%, 패턴 중단, 진행 중이던 예고 장판·열매 제거. 평소 받는 피해는 30%.
- 일정 시간 뒤 재생. 재생 칸에 누가 있으면 비워질 때까지 미룹니다.
- 매듭이 본체 가까이 있어, 멀리서 걸어오다 반격 시간을 날리는 문제를 막습니다.

**패턴** (무작위가 아니라 단계별 고정 순서):

| 패턴 | 예고 | 내용 | 피하는 법 |
| --- | --- | --- | --- |
| 뿌리 줄기 | 0.85초 | 플레이어가 있는 세로줄 전체 | 옆 칸으로 |
| 열매 폭격 | 0.9초 | 플레이어 위치·예측 위치에 곡사 5발 | 착탄 칸 밖으로 |
| 가지 휩쓸기 | 1.2초 | 본체 주변 2칸 링, 후딜 1.2초 | 2걸음 물러난 뒤 반격 |
| 뿌리 장벽 | 1.2초 | 가로줄 2개, 플레이어 가로 좌표 ±2칸 안에 3칸 틈 | 틈으로. 구석 안전지대 제거 |
| 묘목 소환 | 0.9초 | 1칸 근접 소환수, 필드 최대 2마리, 전리품 없음 | 잡거나 무시 |

| 단계 | HP | 순서 |
| --- | --- | --- |
| 1 | 100~60% | 줄기 → 열매 → 휩쓸기 |
| 2 | 60~30% | 줄기 → 장벽 → 열매 → 휩쓸기 |
| 3 | 30~0% | 소환 후 줄기 2줄 → 장벽 → 열매 → 휩쓸기 |

## 4. 초안: 5층 중간 보스 후보 — 거대 멧돼지 (2×2 이동, 미확정)

돌진이 큰 이동을 겸합니다. 착지 끼임 문제가 있는 도약은 넣지 않았습니다. 평소에는 느리게 걷습니다.

| 패턴 | 예고 | 내용 |
| --- | --- | --- |
| 돌진 | 1.0초, 2칸 폭 | 벽에 박으면 1.5~2초 기절(큰 반격 기회). 플레이어에 닿으면 그 앞 줄에 멈춤 |
| 땅 구르기 | 0.9초 | 몸 주변 1칸 링, 후딜 0.8초 |
| 연속 돌격 | 각 0.85초 | HP 50% 이하부터 돌진 2연속 |

보스방은 기둥 없이 넓게 둡니다. 플레이어는 벽을 등지고 돌진을 유도합니다.

## 5. 검토 기록

- 반영: 도약 제거, 장벽 틈 3칸·위치 보장, 예고 시간 연장(1.2초), 매듭 보상 상향, 소환수 상한, 무방비 때 장판 제거.
