# 층계 던전 기획안 (Floor-Based Dungeon)

> 작성일: 2026-11-02 / 상태: **기획 초안 v3 (탈출구 방식 유저 변경: 층 클리어 시 확률 등장, Gemini 재검토 APPROVED, 13절) — 유저 확정 전, 구현 금지**
> 층 방향: 1F → 10F로 **올라간다**. 한 번 올라가면 아래층으로 돌아갈 수 없다.
> 이전 07번 문서(아이작형 방 그리드)는 유저 지시로 폐기하고 이 문서로 대체했다. 넓은 맵 1장 안(시작점 탈출, 귀환길·지름길·순찰조, 맵 프리뷰 3종)도 폐기된 안이다.
> 표기: **[확정]** = 유저가 정한 것, **[추천]** = Claude x Gemini 토론과 Claude 시뮬레이션에서 나온 수치(유저 미확정), **[쟁점]** = 아직 정하지 않은 것.

---

## 0. 개요

| 항목 | 내용 |
| --- | --- |
| 한 줄 요약 | 지역 4개 x 각 10층. 층마다 수작업 고정 층을 풀에서 뽑는다. 층의 몬스터를 모두 잡으면 위층 계단이 열리고, 탈출구가 확률로 나온다. 올라갈수록 가치가 오르고 가방이 찬다. 10층 보스를 잡으면 탈출 |
| 바꾸는 이유 | 넓은 통맵은 짧은 거리 카이팅(타일 스텝 + 장판 회피) 전투와 맞지 않는다. 작은 층을 여러 번 올라가며 매 층 클리어 후 "탈출구가 나왔으면 나갈까, 더 올라갈까"를 판단하게 한다 |
| 재사용 | 기존 `FixedMap` + `DungeonZone` 방식 그대로. 층 하나 = 작은 고정 프리팹 1장 |

## 1. 유저 확정 사항 [확정]

| # | 내용 |
| --- | --- |
| U1 | 지역(맵) 4개, 해금형. 지역 N 보스 첫 처치 **또는** 재료로 만든 통행증 → 지역 N+1 해금. 지역 4 보스 처치 = 엔딩 |
| U2 | 지역마다 10층. 10층은 보스층 고정, 보스 처치 시 탈출구 |
| U3 | 지역마다 층 디자인 풀(수작업 고정 층 여러 장)을 두고 층마다 랜덤/가중치로 뽑는다 |
| U4 | 탈출구는 **층을 클리어한 순간** 층별 확률로 등장. 확률은 층이 높을수록 오르되 상한이 있다(예시 10 / 20 / 30 / 40 / 50% 이후 50% 고정, 재미 검증 필요). 확률은 층별 표로 두어 0 / 100 / 0 / 100 같은 고정 패턴도 설정 가능. (v2의 "탈출구 가능 디자인" 구분은 폐기) |
| U5 | 탈출해야 내 것. 사망 시 가방·장비 전부 손실, 보안 파우치 2칸만 보존 (현재 구현과 같음) |
| U6 | 무게는 삭제된 기획. 가방은 칸 수만 제한 |
| U7 | 층 클리어 = 그 층의 몬스터 **전부** 처치. 클리어해야 위층 계단이 열린다 |
| U8 | 탈출구 보정(기아 방지) 규칙 없음 |
| U9 | 탈출구 위치는 유저가 층 디자인마다 직접 배치한다 |
| U10 | 1F → 10F 상승, 아래층 복귀 없음. 위층으로 올라가면 그 층 탈출구는 사라진다 |

## 2. 기능 A — 층 디자인 풀과 층 생성

| 항목 | 내용 |
| --- | --- |
| **기능명** | 층 디자인 풀 (Floor Design Pool) |
| **핵심 로직** | 층 진입 시 현재 지역 풀에서 "현재 층 번호가 등장 범위 태그에 들어가고, 중복 규칙(Q13)에 걸리지 않는" 디자인을 가중치로 1장 뽑는다 → 프리팹 배치 → 기존 `DungeonGenerator` 구역 배치(BFS 도달 판정, 몬스터 간격 3칸, 시작점 5걸음 안전 반경) 그대로 수행. 탈출구는 층 생성 때 정하지 않고 **클리어 시점**에 굴린다(4절) → 디자인 선택이 탈출구와 무관해진다 |
| **데이터 [추천]** | `FloorDesignSO`: 프리팹, 등장 층 범위(예: 1~4, 3~7, 6~9), 가중치. 층 프리팹 안에 시작점·위층 계단·탈출구 위치 마커를 유저가 배치. `RegionConfigSO`: 지역 번호, 디자인 풀, 층별 탈출구 확률 표(1~9층), 층별 몬스터 구성·배율 표, 보스층 디자인, 해금 조건 |
| **탈출구 마커 [추천]** | 디자인 한 장이 여러 층에 쓰일 수 있고, 어느 층이든 탈출구가 나올 수 있으므로(확률 0% 층 제외) **모든 디자인에 탈출구 마커가 1곳 있어야 한다**. 마커 칸과 주변에는 몬스터·상자를 스폰하지 않는다. 제작 규칙: 위층 계단과 탈출구 마커는 겹치거나 붙이지 않고 최소 3칸 떨어뜨린다(트리거·확인창 간섭 방지 — Gemini v3 검토 MAJOR 2) |
| **풀 크기 [추천]** | 지역당 8~12장, 한 판 안에서 중복 금지. 높은 층은 지형을 재사용하고 몬스터 구성·배율로 난이도를 올린다 (1인 개발 제작량 절감) |
| **풀 크기 문제 (자체 검토)** | 1~9층을 중복 없이 채우려면 한 판에 디자인 **9장**이 필요하다. 8장이면 중복 금지가 성립하지 않고, 층 범위 태그(예: 1~4 / 3~7 / 6~9)로 나누면 범위마다 "그 범위 층 수 + 여유"만큼 있어야 한다. 선택지: ① 최소 12장 ② 중복 금지를 "직전 N층 내 중복 금지"(예: N=3)로 완화 → 8장으로도 가능 [쟁점 Q13] |
| **뷰/시청각** | 층 진입 시 "지역명 3F" 배너, 페이드 |
| **예외/제약** | 후보가 0장이면 조건을 순서대로 풀어 다시 뽑는다: 중복 규칙 해제 → 층 범위 태그 해제. 풀 때마다 경고 로그(Gemini 검토 MAJOR 2). 대안으로 범위 태그를 없애고 난이도는 배율로만 올리는 안도 있음 [Q13]. 10층은 풀과 별개의 보스층 디자인 고정 |

**층 규모 [추천]**

| 층 | 바닥 칸 | 몬스터 | 상자(평균) | 예상 소요 |
| --- | --- | --- | --- | --- |
| 1 | 260 | 4 | 0.8 | 약 62초 |
| 5 | 340 | 6 | 1.2 | - |
| 9 | 380 | 7 | 1.5 | 약 85초 |
| 10 (보스) | 450 | 보스 1 + 잡몹 2 | - | - |

참고: 현재 FixedMap 통맵은 바닥 약 2,771칸이다. 층 하나는 그 1/10 안팎.

## 3. 기능 B — 층 이동

| 항목 | 내용 |
| --- | --- |
| **기능명** | 상승 (Ascend) |
| **핵심 로직** | 층마다 위층 계단 1개(10층 제외). 계단은 처음에 **잠겨 있고**, 층의 몬스터를 모두 잡으면 열린다(U7). 열린 계단 칸에서 확인창 → 위층 생성. 아래층 복귀 없음(U10) |
| **이동 요소 2종** | 위층 계단(같은 던전 안 다음 층, 새로 제작) / 탈출 포탈(허브 귀환, 기존 `DungeonExit` 재사용). 둘은 다른 오브젝트다 |
| **클리어 판정** | 층 생성 때 **실제로 스폰된** 몬스터 수로 카운터를 시작한다(설정값 아님 — `SpawnEntitiesInCells`는 간격·점유 규칙 때문에 목표 수보다 적게 놓을 수 있어서, 설정값으로 세면 영구 클리어 불가. Gemini v3 검토 MAJOR 3). 기존 전역 이벤트 `GlobalEvents.OnMonsterDied(Vector3, int)`가 `FinalizeDeath()`에서 발행되므로(`LootSystem`이 이미 구독) 이를 구독해 줄이고 0이 되면 클리어. `EXPLOSIVE` 특성은 0.75초 퓨즈 뒤 `FinalizeDeath`이므로 그 시점에 센다. 현재 소환 패턴은 없음(보스 소환은 Roadmap) |
| **10층 분기** | 10층은 위층 계단·확률 굴림이 없다. 보스 처치 = 클리어 → 탈출구 100% 활성화(U2). 1~9층 공통 클리어 로직(F3)과 보스층 처리(F6)를 분기한다 (Gemini v3 검토 MINOR 3). 단 10층에는 보스 + 잡몹 2가 있어 "보스만 잡으면 클리어"인지 "보스 포함 전원 처치"인지 정해야 한다(Q23). 보스만이면 `OnMonsterDied(Vector3, int)`에 사망 개체 정보가 없으므로 보스 전용 처치 이벤트가 필요하다 |
| **클리어 판정 [쟁점]** | 보스 소환수 등 나중에 생기는 몬스터를 셀지(Q18), 남은 몬스터 수 표시 여부(Q19, 추천: HUD에 "남은 적 N" 표시 — 안개 속 마지막 1마리를 못 찾는 상황 방지) |
| **방식 [쟁점]** | ① 같은 씬에서 재생성: 타일맵·몬스터·상자·바닥 아이템·안개·`TileSystem` 예약을 지우고 다시 찍은 뒤 플레이어 순간이동. HP·UI·카메라 참조 유지. 주의: 현재 `DungeonGenerator.SpawnPlayerAtCell`은 플레이어 프리팹을 매번 `Instantiate`하므로, 그대로 쓰면 새 플레이어의 `_isInitialized`가 false라 HP가 다시 가득 찬다 → 2층부터는 기존 플레이어를 **재사용하고 위치만 옮기는** 분기가 필요(Gemini 검토 MAJOR 3). `ClearFloor()` 정리 대상: 층 프리팹, 몬스터, 상자, 바닥 아이템, 투사체·장판, 안개 타일맵(`ClearAllTiles` 후 `Initialize` 재호출), `TileSystem` 점유·예약·위험 칸(현재 전체 초기화 메서드 없음 → 추가 필요), 클리어 카운터 리셋(`OnMonsterDied` 구독은 층마다 다시 하지 않고 한 번만 유지하거나, 층마다 해제 후 재구독 — 중복 구독 방지). 누락 시 보이지 않는 벽·안개 잔상(Gemini 검토 MINOR 2). ② 씬 재로드: 기존 던전 입장 경로 재사용. 단 현재 `PlayerStatManager.CalculateStats`가 첫 계산에서 `CurrentHp = MaxHp`로 채우고 `PlayerSessionData`에 HP 필드가 없어서, HP·MP·포션 쿨타임을 따로 저장해야 한다 |
| **HP·MP [쟁점]** | 층 간 유지(회복은 포션으로만) 추천 |
| **예외/제약** | 확인창 동안 `GamePauseService`로 일시정지(투사체·장판 피해도 멈춤). 취소하면 계단 칸을 벗어났다 다시 밟아야 재표시. 계단 칸과 주변 1칸은 몬스터 스폰 금지, 계단은 막다른 1칸 골목에 두지 않는다(몬스터에게 막혀 못 벗어나는 상황 방지 — Gemini 검토 MINOR 1) |

## 4. 기능 C — 탈출구 확률

| 항목 | 내용 |
| --- | --- |
| **기능명** | 층 탈출구 (Floor Exit) |
| **핵심 로직 [확정]** | 층 클리어(마지막 몬스터 처치) 순간 `RegionConfigSO`의 그 층 확률로 1회 굴림 → 성공 시 디자인에 배치된 탈출구 마커에 `DungeonExit`를 활성화. 위층으로 올라가면 사라진다(U10). 보정 규칙 없음(U8) |
| **확률 표 [확정·수치는 예시]** | 1~9층 각각 값을 둔다. 유저 예시: 10 / 20 / 30 / 40 / 50 / 50 / 50 / 50 / 50% (층 x 10%, 상한 50%). 재미 검증 필요 |
| **패턴 예시** | 점증+상한(위 예시) = 운에 기대는 긴장감 / 0, 100, 0, 100 … = 2·4·6·8층 고정 탈출 기회(계획형) / 혼합(일부 층 100% + 나머지 확률) = 보정 규칙 없이도 보장 층을 만들 수 있음. 지역마다 다른 패턴 가능 |
| **10층** | 보스 처치 시 탈출구 (U2). 확률 표와 별개 |
| **활성화 순간 겹침 [추천]** | 현재 `DungeonExit`는 `OnTriggerEnter2D`에서 바로 허브로 전환한다. 플레이어가 마커 칸에 선 채로 마지막 적을 잡으면 원치 않게 즉시 탈출할 수 있다 → 활성화 순간 플레이어가 겹쳐 있으면 무시하고, 칸을 벗어났다 다시 밟아야 발동하게 한다(Gemini v3 검토 MAJOR 1). 탈출에도 계단처럼 확인창을 둘지는 Q22 |
| **뷰/시청각 [추천]** | 클리어 시 "계단이 열렸다" 알림. 탈출구가 생기면 별도 알림 + 위치 표시. 마커가 아직 안개 속 미탐험 칸일 수 있으므로 표시 방식을 정해야 한다: ① 마커 칸 주변 안개 제거 ② 화면 가장자리 방향 화살표 ③ 미니맵 아이콘(미니맵은 아직 없음) — Q20 (Gemini v3 검토 MINOR 1) |
| **아이디어(미채택)** | 다음 층 탈출구 확률을 알려주는 나침반 소모품 |

**예시 확률 계산 (보정 없음)**

| 층 | 확률 | 이 층에서 처음 탈출구가 뜰 확률 | 이 층까지 한 번도 못 봤을 확률 |
| --- | --- | --- | --- |
| 1 | 10% | 10.0% | 90.0% |
| 2 | 20% | 18.0% | 72.0% |
| 3 | 30% | 21.6% | 50.4% |
| 4 | 40% | 20.2% | 30.2% |
| 5 | 50% | 15.1% | 15.1% |
| 6 | 50% | 7.6% | 7.6% |
| 7 | 50% | 3.8% | 3.8% |
| 8 | 50% | 1.9% | 1.9% |
| 9 | 50% | 0.9% | 0.9% |

- 첫 탈출 기회는 3~4층에 몰린다. 4층까지 탈출구를 못 볼 확률 약 30%, 9층까지 못 보고 10층 보스로 가야 할 확률 약 1%
- 이 수치는 "탈출구가 뜨면 반드시 나간다"가 아니라 "탈출 기회가 언제 처음 오는가"다. 실제 재미는 가방 압박(6절)·층별 가치(5절)와 함께 플레이 테스트로 검증한다

## 5. 기능 D — 드랍과 깊이 가치

| 항목 | 내용 |
| --- | --- |
| **일반 몬스터 [추천]** | 1마리당 65% 확률로 전리품 1개 (평균 0.65개) |
| **등급 비율 [추천·가정]** | Common 70 / Rare 25 / Legendary 5 |
| **상자 [추천]** | 재료 2 확정 + 30% 확률로 장비 또는 포션 |

**에디터 테스트 시나리오 (Gemini 검토 제공, 구현 후 사용)**
1. 1층에서 HP 50%로 깎인 채 상승 → 2층에서 HP 50% 유지
2. 확률 표를 0 / 100으로 설정 → 0% 층은 클리어해도 탈출구 없음, 100% 층은 클리어 즉시 마커에 `DungeonExit` 활성화, 상승하면 사라짐
3. 몬스터 1마리를 남김 → 계단 잠김 유지. `EXPLOSIVE` 몬스터가 마지막이면 퓨즈 종료 후 클리어
4. 배낭 착용 상태로 1~6층 진행 → 6층 전후 가방 압박 체감, 가득 찬 상태에서 버리고 바꿔 담기 흐름
5. 1층 절반 탐험 후 상승 → 2층에 안개 잔상 없음, 보이지 않는 벽 없음
6. 탈출구 마커 칸에 선 채로 마지막 몬스터 처치(확률 100%) → 즉시 허브로 튕기지 않음, 벗어났다 다시 밟으면 발동
7. 좁은 층에서 몬스터 목표 6마리 중 4마리만 스폰 → 4마리 처치 시 클리어
8. 확률 100%로 클리어 후 탈출구를 타지 않고 계단으로 상승 → 이전 층 탈출구 소멸, 새 층은 계단 잠김 상태로 시작
9. 미탐험 안개 칸에 탈출구 활성화 → 알림·방향 표시로 위치 식별 가능
