# 층계 던전 기획안 (Floor-Based Dungeon)

> 작성일: 2026-11-02 / 상태: **기획 v7 (유저 질문 Q1~Q32 전부 결정, 11절) — Gemini 검토 후 구현 착수 가능**
> 층 방향: 1F → 10F로 **올라간다**. 한 번 올라가면 아래층으로 돌아갈 수 없다.
> 이전 07번 문서(아이작형 방 그리드)는 유저 지시로 폐기하고 이 문서로 대체했다. 넓은 맵 1장 안(시작점 탈출, 귀환길·지름길·순찰조, 맵 프리뷰 3종)도 폐기된 안이다.
> 표기: **[확정]** = 유저가 정한 것, **[추천]** = Claude x Gemini 토론과 Claude 시뮬레이션에서 나온 수치(유저 미확정), **[쟁점]** = 아직 정하지 않은 것.

---

## 0. 개요

| 항목 | 내용 |
| --- | --- |
| 한 줄 요약 | 지역 4개 x 각 10층. 층마다 수작업 고정 층을 풀에서 뽑는다. 층의 몬스터를 모두 잡으면 위층 계단이 열리고, 탈출구가 확률로 나온다. 올라갈수록 가치가 오르고 가방이 찬다. 10층 보스를 잡으면 탈출 |
| 바꾸는 이유 | 넓은 통맵은 짧은 거리 카이팅(타일 스텝 + 장판 회피) 전투와 맞지 않는다. 작은 층을 여러 번 올라가며 매 층 클리어 후 "탈출구가 나왔으면 나갈까, 더 올라갈까"를 판단하게 한다 |
| 재사용 | 기존 `FixedMap` + `DungeonZone` 방식 그대로. 층 하나 = 작은 고정 프리팹 1장 |

## 1. 유저 확정 사항 [확정]

| U10 | 1F → 10F 상승, 아래층 복귀 없음. 위층으로 올라가면 그 층 탈출구는 사라진다 |

## 2. 기능 A — 층 디자인 풀과 층 생성

| 항목 | 내용 |
| --- | --- |
| **기능명** | 층 디자인 풀 (Floor Design Pool) |
| **핵심 로직** | 층 진입 시 현재 지역 풀에서 "현재 층 번호가 등장 범위 태그에 들어가고, 중복 규칙(Q13)에 걸리지 않는" 디자인을 가중치로 1장 뽑는다 → 프리팹 배치 → 기존 `DungeonGenerator` 구역 배치(BFS 도달 판정, 몬스터 간격 3칸, 시작점 5걸음 안전 반경) 그대로 수행. 탈출구는 층 생성 때 정하지 않고 **클리어 시점**에 굴린다(4절) → 디자인 선택이 탈출구와 무관해진다 |
| **데이터 [추천]** | `FloorDesignSO`: 프리팹, 등장 층 범위(1~5 / 6~9 두 구간, Q13. 5층은 고정 디자인이라 1~5 구간 풀의 실제 추첨은 1~4층), 가중치. 층 프리팹 안에 시작점·위층 계단·탈출구 위치 마커를 유저가 배치. `RegionConfigSO`: 지역 번호, 디자인 풀, 층별 탈출구 확률 표(1~9층), 층별 몬스터 구성·배율 표, 보스층 디자인, 해금 조건 |
| **탈출구 마커 [추천]** | 디자인 한 장이 여러 층에 쓰일 수 있고, 어느 층이든 탈출구가 나올 수 있으므로(확률 0% 층 제외) **모든 디자인에 탈출구 마커가 1곳 있어야 한다**. 마커 칸과 주변에는 몬스터·상자를 스폰하지 않는다. 탈출 포탈은 사실상 디자인마다 고정 위치다. 제작 규칙: 위층 계단과 탈출구 마커는 겹치거나 붙이지 않고 최소 3칸 떨어뜨린다(트리거·확인창 간섭 방지 — Gemini v3 검토 MAJOR 2) |
| **상자 배치 [확정]** | 유저가 디자인에 상자 후보 위치를 지정한다. 지금 `DungeonGenerator`는 `ChestZone` 구역 안 무작위 칸에 `ChestCount`만큼 놓으므로 바꿔야 한다. 뽑기 방식(B안): 층별 확률로 1회 굴림 → 당첨되면 후보 중 무작위 1곳. 최대 2개인 층은 이를 2회 독립으로 굴리고(이미 뽑힌 위치 제외) 0·1·2개 모두 나올 수 있다. 후보를 몇 곳 찍든 상자 확률은 같다 |
| **상자 수치 [추천]** | `RegionConfigSO`에 층별 상자 굴림 횟수·확률 표. 초기값 1~4층 1회, 6~9층 2회, 확률 40%. 2회 층의 분포: 0개 36% / 1개 48% / 2개 16% (평균 0.8개) |
| **몬스터·정예 배치** | 통로·병목 같은 개념은 맵 디자인 요소로 본다. 정예를 "통로·상자·탈출 포탈 주변"에 둔다는 예전 규칙은 쓰지 않는다 |
| **층 구간·중복 [확정, Q13]** | 디자인은 1~5층용 / 6~9층용 두 구간으로 나눠 만든다. 한 판 안에서 같은 디자인은 **절대 중복되지 않는다**. 구간마다 디자인 수를 그 구간 층 수보다 넉넉하게 만든다(1~5층 구간은 5층이 고정이라 실제 추첨 1~4층 → 6장 이상, 6~9층 구간 6장 이상 추천). 높은 층은 몬스터 구성·배율로 난이도를 올린다 |
| **5층 중간 보스 [확정, Q9·Q24]** | 5층은 중간 보스층 고정 디자인이며 **보스층 규칙을 그대로 따른다**(3절 보스층 규칙). 5층이 고정이므로 1~5층 구간 풀은 실제로 1~4층에만 쓰인다 → 5층은 풀 추첨에서 빠진다. 구간 풀은 4장보다 넉넉하게(추천 6장 이상) |
| **뷰/시청각** | 층 진입 시 "지역명 3F" 배너, 페이드. **HUD에 현재 층 상시 표시 [확정, 2026-11-02 유저]** — 탈출구가 나왔을 때 지금 몇 층인지 보고 올라갈지 탈출할지 정하기 위함. 한글 TMP 폰트가 없어 당분간 `Stage 1-3F` 서식으로 표시(서식 문자열만 바꾸면 지역 이름 표시) |
| **예외/제약** | 중복 금지는 완화하지 않는다. 대신 풀 장수가 구간 층 수 이하이면 데이터 오류로 보고 에디터 검증에서 막는다(런타임 후보 0장 방지). 10층은 풀과 별개의 보스층 디자인 고정 |

## 3. 기능 B — 층 이동

| 항목 | 내용 |
| --- | --- |
| **기능명** | 상승 (Ascend) |
| **핵심 로직** | 층마다 위층 계단 1개(10층 제외). 계단은 처음에 **잠겨 있고**, 층의 몬스터를 모두 잡으면 열린다(U7). 열린 계단 칸을 밟으면 **확인창 없이** 바로 위층 생성(Q28 확정). 아래층 복귀 없음(U10). 클리어 순간 플레이어가 계단 칸에 서 있으면 탈출구와 같은 겹침 가드를 적용(벗어났다 다시 밟아야 발동) |
| **클리어 표시 [확정, Q20]** | 일반층은 클리어하는 순간 그 층의 안개가 **전부 사라진다** — 클리어 신호이자 계단·탈출구 위치 공개. 보스층은 처음부터 안개 없이 시작 |
| **이동 요소 2종** | 위층 계단(같은 던전 안 다음 층, 새로 제작) / 탈출 포탈(허브 귀환, 기존 `DungeonExit` 재사용). 둘은 다른 오브젝트다 |
| **클리어 판정** | 층 생성 때 **실제로 스폰된** 몬스터 수로 카운터를 시작한다(설정값 아님 — `SpawnEntitiesInCells`는 간격·점유 규칙 때문에 목표 수보다 적게 놓을 수 있어서, 설정값으로 세면 영구 클리어 불가. Gemini v3 검토 MAJOR 3). 기존 전역 이벤트 `GlobalEvents.OnMonsterDied(Vector3, int)`가 `FinalizeDeath()`에서 발행되므로(`LootSystem`이 이미 구독) 이를 구독해 줄이고 0이 되면 클리어. `EXPLOSIVE` 특성은 0.75초 퓨즈 뒤 `FinalizeDeath`이므로 그 시점에 센다. 일반층은 소환수까지 전부 잡아야 클리어(Q18 확정) → 소환된 몬스터는 스폰될 때 카운터를 +1 한다. 현재 소환 패턴은 없음(보스 소환은 Roadmap) |
| **10층 분기** | 10층은 위층 계단·확률 굴림이 없다. 보스 처치 = 클리어 → 탈출구 100% 활성화(U2). 1~9층 공통 클리어 로직(F3)과 보스층 처리(F6)를 분기한다 (Gemini v3 검토 MINOR 3). 보스층은 **보스만 잡으면 클리어**(Q18·Q23 확정). `OnMonsterDied(Vector3, int)`에는 사망 개체 정보가 없으므로 보스 전용 처치 이벤트가 필요하다 |
| **보스 처치 정리 [확정]** | 보스(10층, 5층 중간 보스 공통) 처치 순간 ① 남은 몬스터 전부 제거(전리품 드랍 없음) ② 날아가는 투사체(`Projectile`)·예고 장판(`AttackWarningUI`) 전부 제거 ③ 플레이어에게 걸린 해로운 상태 이상 해제 ④ 플레이어 무적. **무적은 그 층을 떠나는 즉시 해제**: 탈출(허브 귀환) 또는 위층 계단으로 다음 층 진입(5층 → 6층). 보스를 잡은 뒤 죽는 경로를 없앤다. 현재 상태 이상 시스템·무적 처리는 코드에 없음 → 상태 이상은 도입될 때 이 규칙을 따른다, 무적은 새로 추가 |
| **보스층 규칙 (5층·10층 공통) [확정]** | 안개 없이 시작 / 보스만 처치하면 클리어 / 처치 순간 위 정리 + 무적 / 처치 시 탈출구 **100%**(확률 표 대신) / 귀환석 사용 불가. 차이: 5층은 위층 계단이 열려 6층으로 갈 수 있고(올라가면 무적 해제), 10층은 계단 없이 통행증 첫 처치 드랍(U1) |
| **클리어 시 전투 상태 해제 [추천]** | 전투 중 인벤토리 차단(Q16)은 `PlayerCombatState`(마지막 타격·피격 후 5초)를 쓰므로, 그대로면 마지막 몬스터를 잡은 직후 5초간 가방이 안 열린다. 층 클리어 순간(일반층 전원 처치 / 보스층 보스 처치) 전투 상태를 즉시 비전투로 초기화한다(Gemini v7 검토 MAJOR 3) |
| **남은 몬스터 표시 [확정, Q19]** | 표시하지 않는다. 안개 3단계(`FogOfWarSystem.FogState`: `Visible` 현재 시야 / `Explored` 한 번 밝힌 곳 / `Unexplored` 미탐험)를 그대로 쓴다. 몬스터 행동 범위를 넓게 잡지 않으므로, 안개가 안 걷혔다면 남은 적은 대부분 미탐험(`Unexplored`) 구역에 있고 플레이어는 자연스럽게 그쪽으로 가게 된다. 주의: `Explored` 칸에서는 몬스터가 보이지 않으므로, 몬스터가 이미 탐험한 구역으로 걸어 나오면 찾기 어려워진다 → 몬스터 행동 범위를 좁게 유지하는 것이 이 규칙의 전제 |
| **방식 [쟁점]** | ① 같은 씬에서 재생성: 타일맵·몬스터·상자·바닥 아이템·안개·`TileSystem` 예약을 지우고 다시 찍은 뒤 플레이어 순간이동. | **층 이동 방식 [확정, Q1]** | ① 같은 씬 재생성 |

**예시 확률 계산 (보정 없음, 5층 보스 처치 = 100%)**

| 층 | 확률 | 이 층에서 처음 탈출구가 뜰 확률 | 이 층까지 한 번도 못 봤을 확률 |
| --- | --- | --- | --- |
| 1 | 10% | 10.0% | 90.0% |
| 2 | 20% | 18.0% | 72.0% |
| 3 | 30% | 21.6% | 50.4% |
| 4 | 40% | 20.2% | 30.2% |
| 5 (중간 보스) | 100% | 30.2% | 0% |

- 첫 탈출 기회는 3~5층에 몰린다. 4층까지 탈출구를 못 볼 확률 약 30%이지만, 5층 중간 보스를 잡으면 반드시 탈출 기회가 온다 → 5층이 사실상의 첫 보장 지점
- 6~9층(50%)은 "이 층에서 탈출구가 나올 확률"만 의미가 있다. 6층 이후 연속으로 탈출구를 못 볼 확률: 6층 50% / 6~7층 25% / 6~8층 12.5% / 6~9층 6.25% (6층 이후 탈출구 없이 10층 보스로 가야 할 확률)
- 이 수치는 "탈출구가 뜨면 반드시 나간다"가 아니라 "탈출 기회가 언제 처음 오는가"다. 실제 재미는 가방 압박(6절)·층별 가치(5절)와 함께 플레이 테스트로 검증한다

| **분실 문제 [확정, Q29]** | 보스를 잡고 통행증을 주운 뒤 탈출 전에 죽으면 첫 처치 1회 드랍이라 다음 지역이 영원히 막힌다 → 3절 "보스 처치 정리"(잔여 위협 제거 + 무적)로 보스 처치 후 사망 경로를 없앤다. 예상 못 한 경로(버그 등) 대비 안전장치: 보스 처치 시 **다음 지역이 미해금이고 통행증을 어디에도(가방·보안 파우치·기지 보관) 갖고 있지 않을 때만** 다시 드랍한다. 파우치에 넣고 죽어 통행증을 이미 회수한 경우 중복 드랍되지 않는다(Gemini v7 검토 MINOR 3) |
| **엔딩** | 지역 4 보스 처치. 이후 하드 모드(Heat) 해금으로 연결 (Roadmap 6절) |

**에디터 테스트 시나리오 (Gemini 검토 제공, 구현 후 사용)**
1. 1층에서 HP 50%로 깎인 채 상승 → 2층에서 HP 50% 유지
2. 확률 표를 0 / 100으로 설정 → 0% 층은 클리어해도 탈출구 없음, 100% 층은 클리어 즉시 마커에 `DungeonExit` 활성화, 상승하면 사라짐
3. 몬스터 1마리를 남김 → 계단 잠김 유지. `EXPLOSIVE` 몬스터가 마지막이면 퓨즈 종료 후 클리어
4. 배낭 착용 상태로 1~6층 진행 → 6층 전후 가방 압박 체감, 가득 찬 상태에서 버리고 바꿔 담기 흐름
5. 1층 절반 탐험 후 상승 → 2층에 안개 잔상 없음, 보이지 않는 벽 없음
6. 탈출구 마커 칸에 선 채로 마지막 몬스터 처치(확률 100%) → 즉시 허브로 튕기지 않음, 벗어났다 다시 밟으면 발동
7. 좁은 층에서 몬스터 목표 6마리 중 4마리만 스폰 → 4마리 처치 시 클리어
8. 확률 100%로 클리어 후 탈출구를 타지 않고 계단으로 상승 → 이전 층 탈출구 소멸, 새 층은 계단 잠김 상태로 시작
9. 일반층 클리어 → 안개 전부 해제, 탈출구·계단 위치가 보임. 보스층은 안개 없이 시작
