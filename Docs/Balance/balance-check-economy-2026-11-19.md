## 계산 결과

### 층별 기대치
- 몬스터 1마리 기대 가치 = `0.65 × (일반% × 20 + 희귀% × 80 + 전설% × 300)`. 등급 비율은 1층 70/25/5 → 9층 50/38/12 선형(10층은 9층 값).
- 층의 몬스터 종류는 출현 범위에 드는 종류 중 균등. 몬스터 수는 층 규칙(`_monsterCount`).
- 상자 기대 개수 = `_chestRolls × _chestChance`. 상자 1개 = 일반 재료 2개(6종 균등, 40G) + 30% 보너스(악세서리 3종·HP 포션, 판매가 0).
- 임시 보스(5·10층) = 희귀 이상 2회 굴림(등급 비율에서 일반을 뺀 재정규화) + 설계도 401 30%.
- "특정 일반 재료 1종" = 노드가 요구하는 재료 하나(예: Brute Tooth)의 층당 기대 개수. 몬스터 = `몬스터 수 × 종류 비율 × 0.65 × 일반% / 2`, 상자 = `상자 수 × 2 / 6`.

### 탈출구가 처음 나오는 층 (누적)
1층 10% → 2층 28% → 3층 50% → 4층 70% → 5층 없음(70%) → 6층 85% → 7층 92% → 8층 96% → 9층 98%.
4층까지 탈출구를 못 만나는 30%는 5층 보스를 넘어야 한다.

## 남은 테스트 값
- `Region1Config._debugAllowDuplicateDesigns = 1`: 한 판 디자인 중복 금지 규칙이 꺼져 있음
- 악세서리 14·15·17 `baseValue` 0: 상자 보너스로 23% 나오지만 팔 수 없음
- 잡화상 테스트 판매: 설계도 401 240G(B6), Brute 재료 101·102 40G(U10)

## 평가하지 못한 항목
- 실제 탈출 판단: 몇 층에서 나오는지는 플레이 성향에 달림. 직접 플레이로 확인
- 가방 압박: 층당 약 3~5칸, 기본 25칸이라 6~7층 무렵 가득 참. 버리기 고민이 생기는지는 직접 플레이로 확인
- 0G·무장비 복구: 맨손 1~4층 기대 약 700G로 재제작 100G는 충분. 맨손 전투 생존은 전투 영역이라 이번 범위 밖

## 직접 플레이 체크리스트 (아트 교체 뒤)
1. 장비 없이 1000G로 시작, 재료를 사지 않고 맨손 1~4층 → 탈출·판매. 탈출 층과 가방 상태 기록
2. 1단계 해금까지 걸린 판 수 (계산 약 2~3판)
3. 4층까지 탈출구가 없을 때 5층 보스 처치 가능 여부, 설계도 획득
4. 설계도를 가방과 파우치 중 어디에 둘지 고민이 생기는지
5. 판매(잡화상) ↔ 제작소 동선
6. 일부러 사망한 뒤 남은 골드로 재제작·재출발
