# Void Pouch 개발 태스크 리스트 (Development Tasks)

## 📁 1. Core Systems (전투 및 탐험 코어)
- [ ] **타일 기반 이동 (Grid Movement)**
  - [ ] 키보드 WASD 입력 처리 및 상하좌우 4방향 1칸 이동 로직 (대각선 불가)
  - [ ] 다크 판타지에 어울리는 **'고속 슬라이딩(Dash) 및 잔상'** 이동 애니메이션 구현
- [ ] **마우스 에이밍 및 카이팅 (Twin-stick Combat)**
  - [ ] 마우스 커서 위치를 월드 좌표로 변환 및 8방향 시선 보정(Snap)
  - [ ] 캐릭터 이동 방향(4방향)과 시선/공격 방향(8방향) 분리 (무빙샷 구현)
- [ ] **정교한 타격 시스템 (Micro-Mechanics)**
  - [ ] 이동 중 공격 불가 및 도착 시 즉시 타격을 위한 **선입력(Input Buffering)** 시스템
  - [ ] 공격 속도에 따른 모션 락(제자리 이동 불가 후딜레이) 적용
  - [ ] 무기별 경직(Hitstun) 차별화 (가벼운 무기 무경직 / 무거운 무기 넉백&경직)
  - [ ] 1:N 전투 처리를 위한 광역/단일 타격 판정 (Raycast/OverlapBox)

## 📁 2. Inventory & Items (가방 및 아이템)
- [ ] **인벤토리 코어 시스템 (Slot-based)**
  - [ ] 1칸 1아이템 (1 Slot = 1 Item) 데이터 구조 설계
  - [ ] 아이템 타입 정의 (장비, 소모품, 재료, 열쇠, 탄약 등)
- [ ] **UI 및 상호작용**
  - [ ] 드래그 앤 드롭 아이템 이동/장착/해제
  - [ ] 필드 아이템 루팅 (전리품 팝업 UI)
  - [ ] 아이템 버리기 (휴지통 영구 삭제 및 필드 드롭)
- [ ] **특수 아이템 로직**
  - [ ] 탄약(화살/총알) 스택(중첩) 처리 로직
  - [ ] 미확인 장비 시각화(물음표, 블러) 및 데이터 블라인드 처리

## 📁 3. Weapons & Skills (무기 및 스킬)
- [ ] **무기 시스템**
  - [ ] 클릭 시 해당 방향 타일에 무기 스프라이트 팝업 및 애니메이션 재생
  - [ ] 무기 타입별 고유 피격 범위(Hitbox) 설정
  - [ ] 원거리 무기(활, 소총) 탄약 확인, 차감 및 재장전(Reload) 로직
  - [ ] 마법 무기(지팡이) 지정 타일 오브젝트 생성 및 지연(Delay) 데미지 로직
- [ ] **스킬 시스템 (Item-Bound)**
  - [ ] 무기/방어구에 종속되는 액티브/패시브 스킬 부여 (CC기 등 하드 경직 전담)
  - [ ] 마나(MP) 소모 및 스킬 쿨타임 관리 매니저

## 📁 4. Monsters & AI (몬스터 및 인공지능)
- [ ] **인공지능 및 패스파인딩**
  - [ ] 배회(Patrol) 상태 머신 및 4방향 랜덤 1칸 이동
  - [ ] 타일 기반 4방향 A* 길찾기 알고리즘 구현 (대각선 접근 시 계단식 이동)
  - [ ] 유저 감지(FOV/반경) 및 어그로 추적(Chase) 전환
- [ ] **공격 패턴 및 기믹**
  - [ ] 몬스터 근접/원거리 공격 8방향(대각선 포함) 판정 구현 (사각지대 꼼수 방지)
  - [ ] 장판 공격(Telegraph): N초 후 특정 타일에 데미지를 주는 시각적 경고
  - [ ] 패시브 특성(흡혈, 신속, 자폭 등) 및 보스 특수 패턴

## 📁 5. Map & Generation (맵 생성 및 오브젝트)
- [ ] **절차적 맵 생성 (Procedural Generation)**
  - [ ] 3x3 (9등분) 청크 기반 프리팹 무작위 조립
  - [ ] 하드 모드 진입 시 맵 확장 로직
- [ ] **환경 오브젝트 (Hazards & Shrines)**
  - [ ] 전장의 안개(Fog of War): 캐릭터 반경 N타일 외 시야 차단 및 은폐 시스템 구현
  - [ ] 밟으면 데미지를 입는 함정 (독 늪, 가시 함정 등)
  - [ ] 상호작용 가능한 제단(회복, 버프, 희생)

## 📁 6. Hub & Economy (기지 및 경제)
- [ ] **기지 UI 및 메타 프로그레션**
  - [ ] 상태(State) 기반 클릭형 기지 로비 UI 구현
  - [ ] 상점(소모품 구매), 대장간(장비 매각) 거래 시스템
  - [ ] 감정소(미확인 아이템 감정 후 스탯 오픈 및 골드 차감)
- [ ] **성장 시스템**
  - [ ] 재료를 활용한 영구 스탯(HP, ATK) 업그레이드 제단

## 📁 7. UI/UX (사용자 인터페이스)
- [ ] **게임플레이 HUD**
  - [ ] 하단 고정 액션바 (HP/MP바, 스킬 퀵슬롯, 소모품 퀵슬롯)
  - [ ] 몬스터 정보 호버(Hover) 시 툴팁 및 어그로(?, !) 경고 시각화
- [ ] **팝업 및 특수 UI**
  - [ ] 인벤토리 오픈 시 게임 일시정지(Time.timeScale 제어)
  - [ ] 귀환석 사용 시 화면 중앙 '탈출 카운트다운' 점멸 연출
  - [ ] 던전 종료 후 결과창(정산) 및 사망 시 획득/상실 아이템 대조 패널

## 📁 8. Game Loop & Extraction (게임 루프 및 상태 관리)
- [ ] **익스트랙션 플로우**
  - [ ] 진입(기지 템 셋업) -> 던전 인스턴스 생성 -> 플레이 -> 귀환/사망
  - [ ] 탈출 성공 시 획득 아이템 창고 이전 / 사망 시 인벤토리 전소(Drop)
- [ ] **하드 모드 (Heat System)**
  - [ ] 제약(페널티) 선택 UI 및 난이도 배점(Heat Score) 합산
  - [ ] 위험도에 따른 몬스터 스탯 증가 및 드롭 테이블 확률 스케일링
